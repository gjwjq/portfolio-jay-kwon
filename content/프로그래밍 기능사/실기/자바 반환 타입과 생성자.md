자바에서 메서드를 만들 때는 반환 타입을 반드시 적어야 한다. 반환하는 값이 없을 때도 비워두면 안 되고 
`void`를 적어야 한다. 근데 생성자는 반환 타입을 안 쓰길래 헷갈려서 글 작성.

메서드를 심부름이라고 생각하면 된다. `int add()`는 "계산해서 결과를 가져와", 
`void hello()`는 "가서 인사만 하고 와"다.

**예시 코드**

java

```java
void hello() { ... }        // ✅ 반환값 없음
int add(int a, int b) {     // ✅ int 반환
    return a + b;
}
hello() { ... }             // ❌ 오류: 반환 타입 없음
```

- `void` : 반환하는 값이 없다는 뜻의 반환 타입
- void 메서드에서 `return 값;` → 오류 (`return;`은 가능, 메서드를 바로 끝낸다는 뜻)
- 반환 타입이 있는 메서드에서 return을 안 씀 → 오류

## 생성자

생성자는 객체를 만들 때 처음 값을 세팅하는 용도다. 반환 타입은 "없어도 되는" 게 아니라 **쓰면 안 된다.**

java

```java
class Student {
    String name;

    Student(String n) {     // 생성자
        name = n;
    }

    void Student() { }      // 생성자가 아니라 그냥 일반 메서드
}

Student s = new Student("제이");
```

- 생성자 이름 = 클래스 이름
- 반환 타입을 적으면 안 됨 (`void`도 안 됨) → 적으면 일반 메서드가 됨
- `return 값;` 불가능, `return;`은 가능
- 객체를 돌려주는 건 생성자가 아니라 `new` → `new`가 객체를 만들고, 생성자가 초기값을 세팅하고, `new`가 완성된 객체를 `s`에 넘겨줌
