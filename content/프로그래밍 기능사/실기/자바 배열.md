자바 배열은 같은 타입의 값을 여러 개 담는 상자이고, 크기는 한 번 정하면 바꿀 수 없다. 그런데 문제에서 `Seat[] s = { new Seat(1, true), ... }` 같은 객체 배열이 나와서 헷갈렸다. 기본 배열과 객체 배열을 같이 정리.

## 기본 배열

만드는 방법은 두 가지다. "new 타입[크기]" → 빈 칸만 만들고 기본값으로 채움 (int는 0, boolean은 false, 객체는 null) "{값, 값, 값}" → 만들면서 바로 값 넣기, 크기는 자동

**예시 코드**

java

```java
int[] a = {10, 20, 30};

System.out.println(a[0]);      // 10
System.out.println(a.length);  // 3

for (int x : a) {
    System.out.println(x);     // 10, 20, 30
}
```

- `a[0]` : 인덱스는 0부터, 범위 밖이면 오류
- `a.length` : 배열 길이, 괄호 없음
- `for (int x : a)` : 향상된 for문, 배열 요소를 처음부터 하나씩 x에 넣고 반복

## 객체 배열

클래스로 만든 객체도 배열에 담을 수 있다. "new Seat[4]" → 빈 칸만 만듦, 안은 null, 생성자 실행 X "new Seat(1, true)" → 객체를 만듦, 생성자 실행 O 그래서 빈 칸만 만들고 바로 `s[0].no`를 하면 오류가 난다.

**예시 코드**

java

```java
class Seat {
    int no;
    boolean sold;

    Seat(int n, boolean s) {
        no = n;
        sold = s;
    }
}

Seat[] s = {
    new Seat(1, true),
    new Seat(2, false)
};

System.out.println(s[1].no);    // 2
System.out.println(s[1].sold);  // false
```

- `no = n` : 파라미터 n을 필드 no에 저장, 이름이 다르면 this 생략 가능
- `s[1].no` : 1번 칸 객체의 no 필드, 점 뒤에는 타입이 아니라 필드 이름
- 생성자는 `new Seat(...)`가 적힌 횟수만큼 실행 → 여기선 2번

## static 필드 주의

필드가 `static boolean sold;`이면 객체마다 따로 있지 않고 클래스에 딱 하나만 있다. 그래서 생성자가
실행될 때마다 같은 sold를 덮어쓰고, 마지막에 만든 객체의 값만 남는다. 위 예시에서 sold가 static이라면 `s[0].sold`도 `false`가 나온다. `Seat.sold`, `s[0].sold`, `s[1].sold`는 전부 같은 값이다.
