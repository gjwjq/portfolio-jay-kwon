## 1. floor / ceil / int / round

음수에서 결과가 갈리는 게 헷갈렸다. 수직선 기준으로 어느 쪽으로 가는지만 보면 된다.

python

```python
import math
math.floor(-3.2)   # -4
math.ceil(-3.7)    # -3
int(-3.7)          # -3
-7 // 2            # -4
round(2.5)         # 2
round(3.5)         # 4
```

- `floor`: 작은 쪽 / `ceil`: 큰 쪽 / `int`: 0 쪽으로 자름
- 음수에서는 `floor`와 `int` 결과가 다름
- `//`는 나눈 값에 floor 적용
- 파이썬 `round`는 정확히 .5면 짝수 쪽 (은행가 반올림, 오차가 한쪽으로 안 쌓이게)

## 2. 언어별 round 차이

|코드|2.5|-2.5|
|---|---|---|
|Python `round()`|2|-2|
|JS `Math.round()`|3|-2|
|Java `Math.round()`|3|-2|

- JS·Java는 `floor(x + 0.5)` 방식이라 -2.5 → -2
- Java `Math.round()`는 정수(long/int) 반환

## 3. 소수 근사값 문제

0.1 같은 소수는 2진수로 끝없이 이어져서 근사값으로 저장된다. 파이썬만이 아니라 모든 언어 공통.

python

```python
0.1 + 0.2           # 0.30000000000000004
0.1 + 0.2 == 0.3    # False
round(2.675, 2)     # 2.67
math.isclose(0.1 + 0.2, 0.3)   # True
```

- 0.1, 0.2는 살짝 크게, 0.3은 살짝 작게 저장돼서 다름
- 0.5, 0.25처럼 분모가 2의 거듭제곱이면 정확히 저장
- 자리수 지정 round는 손으로 판단 불가 → 유명 예시만 외우기
- 소수 비교는 `==` 대신 `math.isclose()`

## 4. import 방식

`math`는 파이썬 설치 시 같이 깔려 있지만 자동으로 불러오진 않는다. `round`, `print`, `abs` 같은 내장 함수만 바로 쓸 수 있음.

python

```python
import math              # math.floor() ✅  floor() ❌
import math as m         # m.floor() ✅    math.floor() ❌
from math import floor   # floor() ✅      math.floor() ❌
from math import *       # floor() ✅      math.floor() ❌
```

- import 문에 적힌 이름 그대로만 사용 가능
- JS `Math`는 내장 전역 객체, Java `Math`는 `java.lang` 자동 임포트라 바로 사용

## 5. math 모듈 주요 함수

결과 타입이 함정으로 나온다.

python

```python
math.sqrt(16)      # 4.0
math.gcd(12, 18)   # 6
math.fabs(-5)      # 5.0
abs(-5)            # 5
math.pi            # 3.141592653589793
```

- `sqrt`: 제곱근, 항상 float
- `gcd`: 최대공약수, int
- `fabs`: 절댓값, 항상 float / 내장 `abs`는 정수 넣으면 정수
- `pi`: 상수라서 괄호 없음 (`math.pi()`는 에러)
