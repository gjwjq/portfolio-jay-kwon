## 멀티태스킹

멀티태스킹은 운영체제가 **여러 작업을 동시에 실행하는 것처럼 처리하는 기능**이다.

예시:

```
음악 듣기 / 인터넷 검색 / 파일 다운로드 / 문서 작성
```

실제로 CPU는 여러 작업을 아주 빠르게 번갈아 처리한다.

## 핵심 암기

멀티태스킹 / 여러 작업 동시 처리

---

## 프로세스 스케줄링

프로세스 스케줄링은 **여러 프로세스 중 어떤 프로세스에게 CPU를 줄지 정하는 것**이다.

## 스케줄링 목적

| 목적 | 의미 |
| --- | --- |
| CPU 효율 향상 | CPU가 쉬지 않게 함 |
| 응답 시간 단축 | 사용자 반응을 빠르게 함 |
| 공정한 처리 | 여러 작업이 CPU를 나눠 씀 |
| 처리량 증가 | 더 많은 작업 처리 |

## 핵심 암기

프로세스 스케줄링 / CPU 사용 순서 결정 / CPU 효율성 향상

---

## 선점형 방식

선점형은 운영체제가 실행 중인 작업의 CPU를 **강제로 빼앗을 수 있는 방식**이다.

```
작업 A 실행 중 / 운영체제가 CPU 회수 / 작업 B 실행
```

## 선점형 특징

| 특징 | 의미 |
| --- | --- |
| OS가 CPU 제어 | 운영체제가 CPU를 강제로 회수 가능 |
| 응답 속도 빠름 | 다른 작업으로 빠르게 전환 |
| 시분할에 적합 | 여러 작업을 짧게 번갈아 실행 |
| 문맥 교환 발생 | 작업 전환 비용 발생 |

## 비선점형과 비교

| 구분 | 의미 |
| --- | --- |
| 선점형 | OS가 CPU를 강제로 빼앗음 |
| 비선점형 | 작업이 끝나거나 스스로 반납할 때까지 기다림 |

## 핵심 암기

선점형 / 운영체제가 CPU 강제 회수 / CPU 제어권 OS가 가짐
