## 알파 검사 / 베타 검사

| 구분 | 알파 검사 | 베타 검사 |
| --- | --- | --- |
| 장소 | 개발자 환경 | 사용자 환경 |
| 환경 | 통제된 환경 | 실제 사용 환경 |
| 목적 | 내부 오류 발견 | 실제 사용 문제 발견 |

**외우기:**

알파 = 개발자 쪽

베타 = 사용자 쪽

## 화이트박스 / 블랙박스

| 구분 | 기준 | 기법 |
| --- | --- | --- |
| 화이트박스 | 내부 구조 확인 | 기초 경로, 조건, 루프 |
| 블랙박스 | 입력/출력 확인 | 동치 분할, 경계값, 원인-효과 그래프 |

**외우기:**

화이트 = 내부

블랙 = 입력/출력

## 가상기억장치

| 개념 | 의미 |
| --- | --- |
| 가상기억장치 | 보조기억장치를 주기억장치처럼 사용 |
| 목적 | 실제 메모리보다 큰 프로그램 실행 가능 |
| 페이징 | 같은 크기 블록으로 나눔 |
| 세그먼테이션 | 의미 단위로 나눔 |

**외우기:**

페이징 = 같은 크기

세그먼테이션 = 의미 단위

---

## 페이지 교체 알고리즘

| 기법 | 의미 |
| --- | --- |
| FIFO | 가장 먼저 들어온 페이지 교체 |
| LRU | 가장 오래 사용하지 않은 페이지 교체 |
| LFU | 사용 빈도 가장 낮은 페이지 교체 |
| OPT | 앞으로 가장 오래 안 쓸 페이지 교체 |
| NUR | 최근 사용 안 한 페이지 교체 |

**외우기:**

FIFO = 먼저 들어온 것

LRU = 오래 안 쓴 것

LFU = 적게 쓴 것
