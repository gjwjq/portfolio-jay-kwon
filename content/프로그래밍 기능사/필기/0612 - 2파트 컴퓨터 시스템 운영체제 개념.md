## 1. 인터럽트의 역할

### 핵심

인터럽트는 **CPU가 하던 일을 잠깐 멈추고, 급한 일을 먼저 처리하게 하는 신호**임.

예를 들어 CPU가 프로그램 실행 중인데 키보드를 누르면:

1. CPU가 원래 작업 중
2. 키보드 입력 발생
3. 인터럽트 발생
4. CPU가 잠깐 키보드 입력 처리
5. 다시 원래 작업으로 돌아감

### 예시

| 상황 | 인터럽트 발생 이유 |
| --- | --- |
| 키보드 입력 | 사용자가 키를 누름 |
| 마우스 클릭 | 입력 장치 신호 발생 |
| 프린터 완료 | 입출력 작업 완료 |
| 0으로 나누기 | 오류 발생 |
| 타이머 종료 | CPU 스케줄링 필요 |

### 암기

**인터럽트 = CPU에게 “잠깐 멈추고 이거 먼저 처리해”라고 알리는 신호**

## 2. 멀티프로세싱과 멀티스레딩 차이

## 멀티프로세싱

**프로세스를 여러 개 실행하는 것**임.

프로세스는 실행 중인 프로그램 단위임.

예시:

```
크롬 프로세스
카카오톡 프로세스
노션 프로세스
```

각각 독립적이라 하나가 죽어도 다른 프로세스는 비교적 영향이 적음.

---

## 멀티스레딩

**하나의 프로세스 안에서 여러 작업 흐름을 동시에 처리하는 것**임.

예를 들어 크롬 하나 안에서도:

```
영상 재생 스레드
다운로드 스레드
화면 표시 스레드
입력 처리 스레드
```

이렇게 여러 스레드가 돌아갈 수 있음.

### 비교

| 구분 | 멀티프로세싱 | 멀티스레딩 |
| --- | --- | --- |
| 단위 | 프로세스 여러 개 | 한 프로세스 안의 스레드 여러 개 |
| 메모리 | 보통 독립적 | 같은 메모리 공유 |
| 안정성 | 비교적 높음 | 하나의 오류가 전체에 영향 가능 |
| 속도/자원 | 자원 많이 사용 | 자원 적게 사용 |
| 예시 | 크롬, 노션, 게임 각각 실행 | 크롬 안에서 영상 재생 + 다운로드 |

### 암기

**멀티프로세싱 = 프로그램 여러 개
멀티스레딩 = 한 프로그램 안에서 작업 여러 개**

## 3. 정보 시스템 개념

### 핵심

정보 시스템은 **조직의 업무에 필요한 정보를 수집, 저장, 처리, 제공하는 시스템**임.

예를 들어 학교 정보 시스템이면:

```
학생 정보 저장
성적 관리
출결 관리
수업 관리
공지 제공
```

이런 걸 처리함.

### 구성 요소

| 요소 | 설명 |
| --- | --- |
| 사람 | 사용자, 관리자 |
| 절차 | 업무 처리 방법 |
| 데이터 | 저장되는 정보 |
| 소프트웨어 | 프로그램 |
| 하드웨어 | 컴퓨터, 서버 |
| 네트워크 | 데이터 연결 |

### 암기

**정보 시스템 = 조직 업무를 처리하기 위해 정보와 기술을 묶은 시스템**

## 4. ERP

### 핵심

ERP는 **기업의 모든 자원을 통합 관리하는 정보 시스템**임.

ERP는 `Enterprise Resource Planning`의 약자임.

뜻은:

```
Enterprise = 기업
Resource = 자원
Planning = 계획, 관리
```

즉 기업 자원 관리 시스템.

### ERP가 관리하는 것

| 분야 | 예시 |
| --- | --- |
| 인사 | 직원 정보, 급여 |
| 회계 | 돈 관리, 결산 |
| 생산 | 제품 생산 계획 |
| 물류 | 재고, 배송 |
| 영업 | 판매, 고객 관리 |

### 암기

**ERP = 회사 전체 업무를 하나로 묶어 관리하는 시스템**
