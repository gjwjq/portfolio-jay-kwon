## 1) OSI 7계층 키워드 매칭 (가장 자주 나옴)

> [!tip]
> 문제에서 **키워드**가 보이면, 바로 해당 **계층**을 고르는 유형이 가장 많이 나옵니다.


| 계층 | 핵심 키워드 | 전송 단위 | 대표 장비 |
| --- | --- | --- | --- |
| 1. 물리 계층 | 0과 1, 비트(Bit), 기계적·전기적 특성,물리적 매체 | 비트(Bit) | 리피터, 허브 |
| 2. 데이터 링크 계층 | 프레임, 흐름/오류 제어, 신뢰성, 노드 사이의 데이터 전송 | 프레임(Frame) | 브리지, 스위치 |
| 3. 네트워크 계층 | 경로 설정(Routing), 패킷, IP 주소, 최적 경로, **경로** | 패킷(Packet) | 라우터 |
| 4. 전송 계층 | 종단 간(End-to-End), 신뢰성, 투명한 전송, TCP/UDP | 세그먼트(Segment) | 게이트웨이(L4) |
| 5. 세션 계층 | 대화 제어, 동기점, 세션 연결, 반이중/전이중 | 메시지/데이터 | - |
| 6. 표현 계층 | 암호화, 압축, 형식 변환(ASCII, JPEG), 구문 변환 | 메시지/데이터 | - |
| 7. 응용 계층 | 사용자 인터페이스, 전자우편, HTTP, FTP, SNMP, 사용자/애플리케이션 | 메시지/데이터 | - |

## 2) 프로토콜별 ‘심장’ 키워드 (약자 풀이 포함)

---

- **TCP (Transmission Control Protocol)**: **연결형**, **신뢰성**, 흐름 제어, 순서 제어
- **UDP (User Datagram Protocol)**: **비연결형**, 신뢰성 낮음, **속도 빠름**, 실시간 전송
- **IP (Internet Protocol)**: **비연결형**, 패킷 교환, 주소 지정
- **ICMP (Internet Control Message Protocol)**: **오류 보고**, 메시지 제어, **Ping** 유틸리티
- **ARP (Address Resolution Protocol)**: **논리 주소(IP) → 물리 주소(MAC)** 변환
- **RARP (Reverse ARP)**: **물리 주소(MAC) → 논리 주소(IP)** 변환
- **SNMP (Simple Network Management Protocol)**: 네트워크 **관리**, **감시**, 모니터링
- **HTTP (HyperText Transfer Protocol)**: **웹 페이지** 전송
- **FTP (File Transfer Protocol)**: **파일** 전송
- **SMTP (Simple Mail Transfer Protocol)**: 메일 **보내기**
- **POP3 / IMAP**: 메일 **받기**

---

## 3) 네트워크 장비 1초 컷

- **리피터(Repeater)**: 신호 **증폭**, 거리 연장 (물리 계층)
- **허브(Hub)**: 여러 대 연결, 신호 증폭 포함 (물리 계층)
- **브리지(Bridge)**: LAN과 LAN 연결, **소프트웨어** 방식 (데이터 링크)
- **스위치(Switch)**: MAC 주소, 하드웨어 방식 브리지, 목적지로만 전달 (데이터 링크)
- **라우터(Router)**: **경로 설정**, **최적의 길** 찾기 (네트워크 계층)
- **게이트웨이(Gateway)**: **서로 다른 프로토콜** 망 연결 (전송 계층)

---

## 4) IP 주소 체계 ‘숫자’ 키워드

- **IPv4**: **32**비트, **8**비트씩 **4**부분, **10**진수 표기, 점(`.`) 구분
- **IPv6**: **128**비트, **16**비트씩 **8**부분, **16**진수 표기, 콜론(`:`) 구분
- **IPv6 주소 종류**: 유니캐스트, 멀티캐스트, **애니캐스트** (**브로드캐스트 없음**)
- **서브넷 마스크**: 네트워크 ID와 호스트 ID를 구분하는 마스크
    - A클래스: 255.0.0.0
    - B클래스: 255.255.0.0
    - C클래스: 255.255.255.0

---

## 5) 암기 필살기 (무한 반복)

1. **계층 순서**: 물-데-네-전-세-표-응
2. **프로토콜 3요소**: 구-의-타 (구문, 의미, 타이밍)
3. **오류 제어 / MAC** → 데이터 링크
4. **경로 / 패킷** → 네트워크
5. **신뢰성 / TCP** → 전송
6. **암호화 / 압축** → 표현
7. **IP를 MAC으로** → ARP (A가 주소 알아내는 놈)

---

## 6) 네트워크 핵심 용어 4가지 (시험 키워드만)

- **LAN (Local Area Network)**: **근거리**, 학교/연구소/사무실, **속도 빠름**, 에러율 낮음
- **WAN (Wide Area Network)**: **광역**, 국가/대륙, **속도 상대적으로 느림**, 에러율 높음
- **Ping**: **연결 상태 확인**, **ICMP 사용**, 진단 도구 (OSI **3계층: 네트워크 계층**)
- **패킷(Packet)**: **데이터 전송 단위**, **헤더(IP 등) + 데이터(Payload)**
    - **헤더(Header)**: 출발지/목적지 **IP**, 순서 번호 등
    - **데이터(Payload)**: 실제 내용

### 보너스 키워드 (자주 같이 나옴)

- **대역폭(Bandwidth)**: 한 번에 지나갈 수 있는 데이터의 양
- **지연 시간(Latency)**: 목적지까지 걸리는 시간(왕복 시간)
