## DBMS 필수 기능

| 기능 | 의미 |
| --- | --- |
| 정의 기능 | DB 구조 정의 |
| 조작 기능 | 검색, 삽입, 수정, 삭제 |

DBMS 필수 기능 = 정의 / 조작 / 제어

## DB 설계 단계

| 단계 | 의미 |
| --- | --- |
| 요구 조건 분석 | 사용자가 원하는 것 분석 |
| 개념적 설계 | 현실 세계를 개념적으로 표현 |
| 논리적 설계 | 테이블 구조로 변환 |
| 물리적 설계 | 저장 방법, 성능 고려 |
| 구현 | 실제 DB 생성 |

**외우기:**

요구 → 개념 → 논리 → 물리 → 구현

## 물리적 설계 고려사항

| 고려사항 | 의미 |
| --- | --- |
| 응답 시간 | 처리 속도 |
| 저장 공간 효율 | 공간을 얼마나 효율적으로 쓰는지 |
| 트랜잭션 처리량 | 일정 시간 처리 가능한 작업 수 |

### 물리적 설계 고려사항 아님

| 아님 | 이유 |
| --- | --- |
| 스키마 평가 및 정제 | 논리적 설계 쪽에 가까움 |

**외우기:**

물리적 설계 = 속도 / 저장공간 / 처리량

## View

| 키워드 | 정리 |
| --- | --- |
| View | 가상 테이블 |
| 실제 저장 | 실제 데이터를 따로 저장하지 않음 |
| 기반 | 기본 테이블에서 필요한 부분만 보여줌 |

### View 장점

| 장점 | 의미 |
| --- | --- |
| 보안성 | 필요한 컬럼만 보여줌 |
| 편리성 | 복잡한 질의를 단순화 |
| 독립성 | 기본 테이블 변화 영향 줄임 |

### View 단점

| 단점 | 의미 |
| --- | --- |
| 갱신 제한 | 삽입/수정/삭제가 제한될 수 있음 |
| 인덱스 제한 | 독립적인 인덱스 만들기 어려움 |

**외우기:**

View = 가상 테이블
