# UNIX / LINUX 명령어 🐧

| 명령어 | 풀네임 | 기능 |
| --- | --- | --- |
| ls | list | 파일 목록 |
| pwd | print working directory | 현재 경로 |
| uname | unix name | 시스템 정보 |
| uptime | up time | 부팅 시간 / 사용자 수 |
| cat | concatenate | 파일 내용 출력 |
| chmod | change mode | 권한 변경 |
| chown | change owner | 소유자 변경 |
| cp | copy | 파일 복사 |
| rm | remove | 파일 삭제 |
| cd, chdir | change directory | 디렉터리 이동 |
| rmdir | remove directory | 디렉터리 삭제 |
| mkdir | make directory | 디렉터리 생성 |
| mv | move | 이동 / 이름 변경 |
| tar | tape archive | 파일 묶기, 파일 압축 |
| find | find | 파일 검색 |
| grep | global regular expression print | 문자열 검색 |
| fork | fork | 프로세스 생성 |
| exec | execute | 프로세스 실행 |
| wait | wait | 자식 프로세스 대기 |
| fsck | file system check | 파일 시스템 검사 |
| id | identity | 사용자 정보 |
| last | last | 로그인 기록 |
| who | who | 접속 사용자 |
| getpid | get process id | 프로세스 ID |
| getppid | get parent process id | 부모 프로세스 ID |
| kill | kill | 프로세스 종료 |
| killall | kill all | 동일 이름 프로세스 종료 |
| ps | process status | 프로세스 상태 |
| top | top | 실시간 프로세스 |
| mount | mount | 파일 시스템 연결 |
| umount | unmount | 파일 시스템 해제 |
| ipconfig | ip configuration | 네트워크 정보 |
| host | host | 도메인/IP 조회 |
