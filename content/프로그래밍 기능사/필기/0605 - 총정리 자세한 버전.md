# 1. 프로그래밍 방식 / 패러다임

## 프로그래밍 방식 종류

| 구분 | 핵심 | 특징 | 자주 나오는 포인트 |
| --- | --- | --- | --- |
| 구조적 프로그래밍 | 순차/선택/반복 | Top-Down, 모듈화, 유지보수 쉬움 | GOTO 사용 X |
| 절차적 프로그래밍 | 순서 중심 | 절차를 순서대로 실행 | C 언어 느낌 |
| 객체지향 프로그래밍 | 객체 중심 | 캡슐화, 상속, 다형성, 추상화 | 클래스/객체/메서드 |
| 이벤트 중심 프로그래밍 | 이벤트 발생 중심 | 클릭, 입력, 선택에 반응 | GUI 프로그램 |
| 함수형 프로그래밍 | 함수 중심 | 부작용 최소화, 함수 조합 | 람다, 순수 함수 |

**외우기**

구조적 = 순차/선택/반복

객체지향 = 객체 중심

이벤트 중심 = 클릭하면 실행

함수형 = 함수 중심

---

## 객체지향 구성 요소

| 개념 | 의미 |
| --- | --- |
| 클래스 | 객체를 만들기 위한 설계도 |
| 객체 | 실제로 만들어진 대상 |
| 속성 | 객체가 가진 데이터 |
| 메서드 | 객체가 수행하는 기능 |
| 메시지 | 객체에게 작업을 요청하는 것 |

---

## 객체지향 특징

| 특징 | 의미 |
| --- | --- |
| 캡슐화 | 데이터와 기능을 묶고 숨김 |
| 정보 은닉 | 외부에서 내부 데이터 접근 제한 |
| 상속 | 부모 기능을 자식이 물려받음 |
| 다형성 | 같은 이름이 상황에 따라 다르게 동작 |
| 추상화 | 중요한 특징만 뽑아 표현 |

**외우기**

객체 = 속성 + 메서드

클래스 = 설계도

캡슐화 = 정보 은닉

# 2. 변수명 표기법

## 표기법 종류

| 표기법 | 특징 | 예시 |
| --- | --- | --- |
| 헝가리안 표기법 | 변수명 앞에 자료형/의미 표시 | `strName`, `intAge` |
| 카멜 케이스 | 첫 단어 소문자, 다음 단어부터 대문자 | `studentName` |
| 파스칼 케이스 | 모든 단어 첫 글자 대문자 | `StudentName` |
| 스네이크 케이스 | 단어 사이를 `_`로 연결 | `student_name` |
| 케밥 케이스 | 단어 사이를 `-`로 연결 | `student-name` |
| 상수 표기법 | 모두 대문자 + `_` | `MAX_VALUE` |

---

## 시험 포인트

| 나오면 | 답 |
| --- | --- |
| 변수명에 자료형 표시 | 헝가리안 표기법 |
| `studentName` | 카멜 케이스 |
| `StudentName` | 파스칼 케이스 |
| `student_name` | 스네이크 케이스 |
| `student-name` | 케밥 케이스 |
| `MAX_VALUE` | 상수 표기법 |

**외우기**

헝가리안 = 자료형

카멜 = 중간 대문자

파스칼 = 처음도 대문자

스네이크 = 밑줄

케밥 = 하이픈

상수 = 대문자

# 5. 예외 처리

## 예외 처리 구문

| 구문 | 의미 |
| --- | --- |
| try | 오류가 날 수 있는 코드 |

| 상황 | 순서 |
| --- | --- |

| 오류 있음 | try → catch → finally |

**외우기**

try = 시도

catch = 잡기

finally = 무조건
