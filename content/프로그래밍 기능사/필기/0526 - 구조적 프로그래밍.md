### 구조적 프로그래밍

**뜻**

**복잡한 프로그램을 다루기 쉽도록 모듈 단위로 나누고, 순차, 선택, 반복이라는 세 가지 제어 구조만을 사용하여 프로그램의 흐름을 이해하고 유지보수하기 쉽게 만드는 프로그래밍 패러다임**

goto문을 배제함.

**기본 구조 3가지**

| 구조 | 뜻 | 예시 |
| --- | --- | --- |
| 순차 구조 | 위에서 아래로 차례대로 실행 | 일반 코드 |
| 선택 구조 | 조건에 따라 실행 | `if`, `switch` |
| 반복 구조 | 조건 동안 반복 실행 | `for`, `while` |

### 1. 순차 구조

위에서 아래로 차례대로 실행.

```
a=10;
b=20;
sum=a+b;
```

### 2. 선택 구조

조건에 따라 갈림.

```
if (score>=60)
printf("합격");
else
printf("불합격");
```

### 3. 반복 구조

조건 동안 반복.

```
for (i=1;i<=5;i++)
printf("%d",i);
```

**목적**

- 프로그램을 이해하기 쉽게 함
- 오류 수정이 쉬움
- 유지보수가 쉬움

**키워드**

> 순차 / 선택 / 반복 / GOTO 사용 억제 / 가독성 / 유지보수
