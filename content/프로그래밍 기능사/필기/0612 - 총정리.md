# 마지막 전체 개념 총정리

| 개념 | 한 줄 암기 |
| --- | --- |
| List Comprehension | 리스트를 for문으로 한 줄에 만드는 문법 |
| 튜플 | 수정 불가능한 리스트 |
| with문 | 파일 같은 자원을 자동으로 닫아주는 문법 |
| 구조체 `.` | 구조체 변수의 멤버 접근 |
| 구조체 `->` | 구조체 포인터의 멤버 접근 |
| `&` | 변수의 주소를 가져옴 |
| `*` | 포인터 선언 또는 주소를 따라가 값 접근 |
| malloc | 실행 중 필요한 메모리를 동적으로 할당 |
| free | malloc으로 빌린 메모리 해제 |
| 인터럽트 | CPU에게 급한 일을 먼저 처리하라고 알리는 신호 |
| 멀티프로세싱 | 프로세스 여러 개 실행 |
| 멀티스레딩 | 한 프로세스 안에서 스레드 여러 개 실행 |
| 정보 시스템 | 조직 업무에 필요한 정보를 처리하는 시스템 |
| ERP | 기업 전체 자원을 통합 관리하는 시스템 |
| IaaS | 서버, 저장소 같은 인프라를 빌림 |
| PaaS | 개발 플랫폼을 빌림 |
| SaaS | 완성된 소프트웨어를 인터넷으로 사용 |
| HaaS | 하드웨어를 서비스처럼 빌림 |
| 정보보안 3요소 | 기밀성, 무결성, 가용성 |
| 패킷 | 데이터를 작게 나눈 조각 |
| 패킷 교환 | 데이터를 패킷 단위로 나눠 전송 |
| 성형 토폴로지 | 중앙 장치 중심으로 노드들이 연결된 구조 |
| NAT | 사설 IP를 공인 IP로 변환 |
| LIKE `%` | 글자 수 상관없는 아무 문자열 |
| 디지털 서명 | 인증, 무결성, 부인 방지 |
| 결합도 순위 | 자료→스탬프→제어→외부→공통→내용 |
| 수정 유지보수 | 오류 고침 |
| 적응 유지보수 | 환경 변화에 맞춤 |
| 완전 유지보수 | 기능/성능 개선 |
| 예방 유지보수 | 미래 오류 방지 |
| SDLC | 계획→분석→설계→구현→테스트→유지보수 |
| 애자일 | 짧게 만들고 피드백 받아 계속 개선 |
| CI/CD | 자동 빌드, 테스트, 배포 |
| CI/CD 도구 | Jenkins, GitHub Actions, GitLab CI/CD 등 |

## 진짜 시험 직전 압축 암기

```
튜플 = 수정 불가
with = 자동 close
& = 주소
* = 주소 따라 값
malloc = 메모리 동적 할당
인터럽트 = CPU 긴급 호출
멀티프로세싱 = 프로세스 여러 개
멀티스레딩 = 스레드 여러 개
ERP = 기업 자원 통합 관리
CIA = 기밀성 무결성 가용성
패킷 = 데이터 조각
성형 = 중앙 장치 중심
NAT = 사설 IP → 공인 IP
LIKE % = 아무 문자열
디지털서명 = 인증 무결성 부인방지
결합도 = 자스제외공내
유지보수 = 수정 적응 완전 예방
SDLC = 계획 분석 설계 구현 테스트 유지보수
애자일 = 반복 + 피드백 + 변화 대응
CI/CD = 자동 통합/배포
```
