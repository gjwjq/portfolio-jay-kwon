### 전송 계층 / 제어 키워드

- **신뢰성, 흐름 제어, 연결형(빠름/안정적)** → **TCP**
- **비연결형(실시간)** → **UDP**

### 네트워크 계층 / 보조 프로토콜 키워드

- **오류 보고, ping** → **ICMP**
- **IP → MAC** → **ARP**
- **MAC → IP** → **RARP**

### 응용 계층 (서비스 ↔ 포트 ↔ 프로토콜)

| 서비스(키워드) | 프로토콜 | 포트 |
| --- | --- | --- |
| 웹 페이지 | HTTP | 80 |
| 암호화 웹(SSL/TLS) | HTTPS | 443 |
| 파일 전송 | FTP | 20, 21 |
| 메일 보내기 | SMTP | 25 |
| 메일 받기 | POP3 | (대표) 110 |
| 메일 받기(동기화) | IMAP | (대표) 143 |
| 도메인 → IP | DNS | 53 |
| IP 자동 할당 | DHCP | (대표) 67/68 |
| 네트워크 관리/모니터링 | SNMP | (대표) 161/162 |
| 원격 접속 | Telnet | 23 |
| 보안 원격 접속 | SSH | 22 |

### 라우팅 프로토콜 정리 (키워드 ↔ 답)

- **RIP**
    - 키워드: **홉 수**, **15홉 제한**, **소규모**
- **OSPF**
    - 키워드: **링크 상태**, **다익스트라**, **대규모**
- **BGP**
    - 키워드: **AS 간**, **인터넷 백본**, **ISP**
- **IGRP**
    - 키워드: **Cisco 전용**, **혼합형**
