# DOS / CLI 명령어 💻

| 명령어 | 풀네임 | 기능 |
| --- | --- | --- |
| DIR | directory | 파일 목록 |
| TYPE | type | 파일 내용 출력 |
| COPY | copy | 파일 복사 |
| DEL | delete | 파일 삭제 |
| REN | rename | 이름 변경 |
| CLS | clear screen | 화면 지우기 |
| VER | version | 버전 확인 |
| MD | make directory | 디렉터리 생성 |
| CD | change directory | 디렉터리 이동 |
| RD | remove directory | 디렉터리 삭제 |
| PATH | path | 경로 설정 |
| VOL | volume | 볼륨 정보 |
| LABEL | label | 볼륨명 변경 |
| TIME | time | 시간 설정 |
| DATE | date | 날짜 설정 |
| EXIT | exit | 종료 |
| FORMAT | format | 디스크 초기화 |
| CHKDSK | check disk | 디스크 검사 |
| ATTRIB | attribute | 속성 변경 |
| XCOPY | extended copy | 디렉터리 복사 |
| SORT | sort | 정렬 |
| MORE | more | 페이지 출력 |
| FIND | find | 문자열 검색 |

---

# DIR 옵션 📂

| 옵션 | 기능 |
| --- | --- |
| /ON | 이름순 정렬 |
| /O-N | 이름 역순 |
| /P | 한 화면씩 |
| /W | 가로 출력 |
| /S | 하위 디렉터리 포함 |
| /E | 확장자순 |

---

# ATTRIB 속성 🏷️

| 속성 | 의미 |
| --- | --- |
| R | Read Only |
| H | Hidden |
| + | 속성 부여 |
| - | 속성 해제 |

---

# XCOPY 옵션 📁

| 옵션 | 기능 |
| --- | --- |
| /E | 빈 디렉터리 포함 |
| /S | 하위 디렉터리 포함 |

---

# 와일드카드 ✨

| 기호 | 의미 |
| --- | --- |
| * | 모든 문자열 |
| ? | 한 글자 |

| 예시 | 의미 |
| --- | --- |
| DIR *.MP3 | 모든 MP3 |
| DIR 소주*.MP3 | 소주로 시작 |
| DIR 소주??.MP3 | 소주 + 뒤 2글자 |
