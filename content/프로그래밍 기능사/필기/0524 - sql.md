### SQL 분류

- **DDL (Data Definition Language)**: 구조 관리
    - `CREATE`, `ALTER`, `DROP`, `TRUNCATE`, `RENAME`
- **DML (Data Manipulation Language)**: 데이터 관리
    - `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- **DCL (Data Control Language)**: 권한/제어 관리
    - `GRANT`, `REVOKE`, `COMMIT`, `ROLLBACK`

---

### 주요 키워드 정리

#### GRANT (권한 부여)

- 의미: 사용자에게 권한을 **준다**
- 예시

```sql
GRANT SELECT ON 학생 TO user1;
```

- 해석: `user1`에게 `학생` 테이블 **조회(SELECT) 권한**을 부여
- 암기: **GRANT = 권한 주기**

#### REVOKE (권한 회수/취소)

- 의미: 사용자에게서 권한을 **뺏는다**
- 예시

```sql
REVOKE SELECT ON 학생 FROM user1;
```

- 해석: `user1`의 `학생` 테이블 **조회(SELECT) 권한**을 회수
- 암기: **REVOKE = 권한 뺏기**

#### DISTINCT (중복 제거)

- 의미: 조회 결과에서 **중복을 제거**
- 예시

```sql
SELECT DISTINCT 학과 FROM 학생;
```

- 해석: `학생` 테이블에서 `학과`를 조회하되 **중복 값은 제거**
- 암기: **DISTINCT = 중복 제거**

#### LIKE (문자열 패턴 검색)

- 의미: 문자열 **포함/패턴**으로 검색
- 사용 예

```sql
SELECT *
FROM 고객
WHERE 직책 LIKE '%부장%';
```

- 뜻: `직책`에 '부장'이 **포함**된 레코드 검색
- 와일드카드
    - `%` : 아무 문자 **여러 개**
        - `'부장%'` : 부장으로 시작
        - `'%부장'` : 부장으로 끝남
        - `'%부장%'` : 부장을 포함
    - `_` : 아무 문자 **1개**
        - `'_부장'` : 앞에 한 글자 + 부장
        - `'부_장'` : 부 + 한 글자 + 장
- 암기: **LIKE = 포함/패턴**, **% = 여러 글자**, **_ = 한 글자**
