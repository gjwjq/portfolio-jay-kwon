## 시스템 카탈로그

시스템 카탈로그는 **데이터베이스의 구조와 객체 정보를 저장하는 곳**이다.

저장 정보:

```
테이블 정보 / 컬럼 정보 / 인덱스 정보 / 뷰 정보 / 권한 정보 / 제약조건 정보
```

## 핵심 암기

시스템 카탈로그 / DB 구조와 객체 정보 저장

---

## DBA

DBA는 **Database Administrator**, 즉 데이터베이스 관리자이다.

## DBA 역할

| 역할 | 의미 |
| --- | --- |
| DB 설계 | 데이터베이스 구조 설계 |
| 권한 관리 | 사용자 권한 부여와 회수 |
| 백업과 복구 | 데이터 손실 대비 |
| 보안 관리 | 접근 제어 |
| 성능 관리 | DB 속도 개선 |
| 무결성 관리 | 데이터 정확성 유지 |

## DBA 구성요소로 보기 어려운 것

```
응용 라이브러리
```

응용 라이브러리는 애플리케이션 개발에 쓰는 코드 묶음에 가깝다.

## 핵심 암기

DBA / 데이터베이스 관리자 / 설계 권한 백업 복구 보안 성능 관리

---

## 백업

백업은 **데이터 손실에 대비해서 복사본을 만들어 두는 것**이다.

## 백업 용량 산정 시 고려할 것

| 요소 | 의미 |
| --- | --- |
| 전체 데이터 크기 | 현재 백업할 데이터 양 |
| 데이터 성장률 | 앞으로 데이터가 얼마나 늘어날지 |
| 백업 주기 | 매일, 매주, 매월 등 |
| 보관 기간 | 백업본을 얼마나 오래 저장할지 |
| 압축 여부 | 압축하면 용량이 줄 수 있음 |

## 핵심 암기

백업 용량 / 전체 데이터 크기 / 성장률 / 백업 주기 / 보관 기간
