## Java 2차원 배열

```
int[][]arr= {
    {1,2,3},
    {4,5,6}
};
```

| 표현 | 의미 |
| --- | --- |
| `arr[0][0]` | 1 |
| `arr[0][1]` | 2 |
| `arr[1][0]` | 4 |
| `arr[1][2]` | 6 |

**보는 법:**

앞 번호 = 행

뒤 번호 = 열

`arr[1][2]`

→ 1번 행, 2번 열

→ 값은 6

---

## 배열 인덱스

| 키워드 | 정리 |
| --- | --- |
| 인덱스 | 배열 번호 |
| 시작 | 0부터 시작 |
| `arr[0]` | 첫 번째 값 |
| `arr[1]` | 두 번째 값 |

## 데이터 백업 방식

| 백업 방식 | 정리 |
| --- | --- |
| 전체 백업 | 모든 데이터를 백업 |
| 증분 백업 | 마지막 백업 이후 변경된 것만 백업 |
| 차등 백업 | 마지막 전체 백업 이후 변경된 것 백업 |
| 미러 백업 | 원본과 똑같이 복사 |

### 헷갈리는 것

| 구분 | 기준 |
| --- | --- |
| 증분 백업 | 직전 백업 이후 |
| 차등 백업 | 마지막 전체 백업 이후 |

**외우기:**

증분 = 조금씩 이어서

차등 = 전체 백업 기준으로 계속 누적

---

## 데이터 백업 예시

월요일 전체 백업

화요일 파일 A 변경

수요일 파일 B 변경

| 방식 | 수요일 백업 내용 |
| --- | --- |
| 증분 백업 | 수요일에 바뀐 B만 |
| 차등 백업 | 화요일 A + 수요일 B |
