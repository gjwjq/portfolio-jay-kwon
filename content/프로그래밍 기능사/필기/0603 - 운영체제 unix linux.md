## 커널 Kernel

| 키워드 | 정리 |
| --- | --- |
| 커널 | 운영체제의 핵심 |

## 쉘 Shell

| 키워드 | 정리 |

| 쉘 | 명령어 해석기 |

## chmod 번호

| 권한 | 숫자 | 의미 |
| --- | --- | --- |
| r | 4 | read, 읽기 |
| w | 2 | write, 쓰기 |
| x | 1 | execute, 실행 |

| 예시 | 의미 |
| --- | --- |
| `chmod 777 file` | 모든 사용자 읽기/쓰기/실행 |
| `chmod 755 file` | 소유자 전부 가능, 나머지는 읽기/실행 |
| `chmod 644 file` | 소유자 읽기/쓰기, 나머지는 읽기만 |
| `chmod 700 file` | 소유자만 전부 가능 |

**계산법:**

`rwx = 4+2+1 = 7`

`rw- = 4+2 = 6`

`r-x = 4+1 = 5`

`r-- = 4`

## 교착상태 Deadlock

| 키워드 | 정리 |
| --- | --- |
| 교착상태 | 프로세스들이 서로 자원을 기다리면서 멈춘 상태 |
| 쉽게 | A는 B가 가진 자원 기다림, B는 A가 가진 자원 기다림 |
| 나오는 파트 | 운영체제 - 프로세스 / 자원 관리 |

### 교착상태 발생 조건 4개

| 조건 | 의미 |
| --- | --- |
| 상호 배제 | 자원을 한 번에 하나의 프로세스만 사용 |
| 점유와 대기 | 자원을 가진 상태에서 다른 자원 기다림 |
| 비선점 | 남의 자원을 강제로 빼앗을 수 없음 |
| 환형 대기 | 서로 원형으로 자원을 기다림 |

**외우기:**

상점비환

= 상호 배제, 점유와 대기, 비선점, 환형 대기

## 메모리를 프로그램에 배정하는 작업

| 키워드 | 정리 |
| --- | --- |
| 메모리 할당 | 프로그램이 실행될 수 있도록 메모리 공간을 배정하는 것 |
| 정적 할당 | 실행 전에 메모리 크기 결정 |

## CPU 처리 방식

| 방식 | 정리 |
| --- | --- |
| 일괄 처리 | 작업을 모아서 한 번에 처리 |
| 실시간 처리 | 결과가 즉시 필요할 때 처리 |
| 시분할 처리 | CPU 시간을 쪼개 여러 사용자에게 번갈아 제공 |
| 다중 프로그래밍 | 여러 프로그램을 메모리에 두고 CPU 사용률 높임 |
| 다중 처리 | CPU 여러 개로 동시에 처리 |
| 분산 처리 | 여러 컴퓨터가 작업을 나눠 처리 |

**자주 나오는 말:**

시분할 = 시간 쪼개기

실시간 = 즉시 응답

분산 = 여러 컴퓨터가 나눔
