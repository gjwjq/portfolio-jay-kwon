## 작업 관리자

작업 관리자는 Windows에서 실행 중인 프로그램과 프로세스 상태를 확인하는 도구이다.

확인 가능한 것:

```
실행 중인 프로그램 / 프로세스 / CPU 사용량 / 메모리 사용량 / 디스크 사용량 / 네트워크 사용량
```

## 단축키

```
Ctrl + Shift + Esc
```

## 핵심 암기

작업 관리자 / Ctrl + Shift + Esc / 프로세스 상태 확인

---

## 핫스와핑

핫스와핑은 **시스템을 끄거나 재부팅하지 않고 장치를 연결하거나 분리하는 기능**이다.

예시:

```
USB 연결 / 외장하드 연결 / 마우스 연결 / 키보드 연결
```

## 핵심 암기

핫스와핑 / 재부팅 없이 장치 연결 또는 분리

---

## 파일 시스템

파일 시스템은 **운영체제가 파일을 저장하고 관리하는 방식**이다.

| 파일 시스템 | 설명 |
| --- | --- |
| NTFS | Windows에서 많이 사용 |
| FAT32 | USB에서 자주 사용 |
| exFAT | 대용량 USB, 외장 저장장치 |
| ext4 | Linux에서 많이 사용 |

## 헷갈리는 용어

| 용어 | 정체 |
| --- | --- |
| NTFS | 파일 시스템 |
| HTTP | 웹 통신 프로토콜 |
| FTP | 파일 전송 프로토콜 |
| TCP | 전송 계층 프로토콜 |

## 핵심 암기

파일 시스템 / 파일 저장 관리 방식 / NTFS

---

## 가상 메모리

가상 메모리는 **RAM이 부족할 때 보조기억장치 일부를 메모리처럼 사용하는 기능**이다.

```
RAM 부족 / 디스크 일부 사용 / 메모리처럼 활용
```

## 가상 메모리 역할

| 역할 | 의미 |
| --- | --- |
| 메모리 부족 보완 | RAM보다 큰 프로그램 실행 가능 |
| 다중 프로그램 실행 지원 | 여러 프로그램 실행 가능 |
| 메모리 효율 향상 | 필요한 부분만 메모리에 올림 |

## 가상 메모리가 아닌 것

```
CPU 속도 향상 아님 / 저장장치 오류 방지 아님
```

## 핵심 암기

가상 메모리 / 디스크를 메모리처럼 사용
