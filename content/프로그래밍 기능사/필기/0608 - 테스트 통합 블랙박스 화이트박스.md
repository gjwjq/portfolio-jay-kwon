## 통합 테스트

통합 테스트는 **여러 모듈을 연결했을 때 제대로 동작하는지 확인하는 테스트**이다.

예시:

```
로그인 모듈 / 회원 DB 모듈 / 화면 출력 모듈
```

각각 따로는 정상이어도 연결하면 오류가 날 수 있다.

## 통합 테스트 확인 대상

```
모듈 간 연결 / 인터페이스 오류 / 데이터 흐름 / 기능 연동
```

## 핵심 암기

통합 테스트 / 모듈 간 인터페이스와 데이터 흐름 검증

---

## 블랙박스 테스트

블랙박스 테스트는 **내부 코드를 보지 않고 기능이 요구사항대로 동작하는지 확인하는 테스트**이다.

## 블랙박스 기준

```
사용자 요구사항 / 입력값과 출력값 / 기능 동작 결과
```

## 대표 기법

```
동치 분할 / 경계값 분석 / 오류 예측 / 원인-결과 그래프
```

## 핵심 암기

블랙박스 테스트 / 내부 코드 안 봄 / 사용자 요구사항 기준 기능 테스트

---

## 화이트박스 테스트

화이트박스 테스트는 **내부 코드 구조를 보고 테스트하는 방식**이다.

## 화이트박스 확인 대상

```
모든 코드 실행 여부 / 조건문 분기 / 실행 경로 / 내부 로직
```

## 대표 기법

```
문장 검증 / 분기 검증 / 조건 검증 / 경로 검증
```

## 핵심 암기

화이트박스 테스트 / 내부 코드 구조 확인 / 분기와 경로 실행 여부 확인
