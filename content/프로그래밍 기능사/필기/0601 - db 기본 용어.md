# 시험 직전 초압축

```
**속성 = 열
속성값 = 한 칸
튜플 = 행
릴레이션 = 테이블
스키마 = 구조
인스턴스 = 실제 데이터 , 모든 튜플
차수 = 열 개수
기수 = 행 개수
도메인 = 값 범위**
```

# 1. 속성 (Attribute)

- **테이블의 열(Column) 1개**

• 데이터 항목 이름

예시

```
도서번호 / 도서이름 / 출판사 / 가격
```

→ `도서번호` 하나가 속성

→ `도서이름` 하나가 속성

한줄암기

**속성 = 열(Column)**

---

# 2. 속성값 (Attribute Value)

- 속성 안에 들어있는 **실제 값**

• 한 칸 데이터

예시

```
도서번호 → 1
도서이름 → 축구의 역사
가격 → 7000
```

→ `1`, `축구의 역사`, `7000` 이 속성값

한줄암기

**속성값 = 한 칸 값**

---

# 3. 튜플 (Tuple) = 레코드(Record)

- **행(Row) 1줄**

• 하나의 데이터 묶음

예시

```
(1, 축구의 역사, 굿스포츠, 7000)
```

→ 한 줄 전체가 튜플

한줄암기

**튜플 = 행(Row)**

---

# 4. 릴레이션 (Relation)

- **테이블 자체**

예시

```
도서 테이블
```

→ 도서 테이블 전체 = 릴레이션

한줄암기

**릴레이션 = 테이블**

---

# 5. 스키마 (Schema)

- **테이블 구조(설계도)**

• 어떤 속성들로 구성되는지 정의

예시

```
도서(도서번호, 도서이름, 출판사, 가격)
```

→ `도서번호` 하나 = 속성 (스키마❌)

→ **다 합친 구조 = 스키마 ⭕**

한줄암기

**스키마 = 구조(설계도)**

---

# 6. 인스턴스 (Instance)

- **현재 저장된 실제 데이터 전체**

• 특정 시점의 데이터 상태

예시

```
(1, 축구의 역사, 굿스포츠, 7000)
(2, 축구아는 여자, 나무수, 13000)
```

→ 저장된 데이터 전체 = 인스턴스

한줄암기

**인스턴스 = 실제 데이터**

---

# 7. 차수 (Degree)

- **속성(열)의 개수**

예시

```
도서번호 / 도서이름 / 출판사 / 가격
```

→ 열 4개

```
차수 = 4
```

주의

```
도서(도서번호, 도서이름, 출판사, 가격)
```

이건 **스키마**

```
4
```

이게 **차수**

한줄암기

**차수 = 열 개수**

---

# 8. 기수 (Cardinality)

- **튜플(행)의 개수**

예시

```
1. 축구의 역사
2. 축구아는 여자
```

→ 행 2개

```
기수 = 2
```

한줄암기

**기수 = 행 개수**

---

# 9. 도메인 (Domain)

- **속성이 가질 수 있는 값의 범위(자료형)**

• 속성마다 하나씩 존재

예시

```
도서번호 → 정수(INT)
도서이름 → 문자(VARCHAR)
출판사 → 문자(VARCHAR)
가격 → 정수(INT)
```

쉽게 생각

```
속성 = 칸 이름
도메인 = 그 칸 규칙
```

예)

```
가격 → 숫자만 가능
```

한줄암기

**도메인 = 값 범위(자료형)**
