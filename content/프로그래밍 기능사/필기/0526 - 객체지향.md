# 객체지향 프로그래밍(OOP) 4대 특징

## 1. 캡슐화 (Encapsulation)

**데이터(변수)와 메서드(기능)를 하나로 묶고 정보를 숨기는 것**

- 데이터 보호(정보 은닉)
- 외부 접근 제한
- `private` 사용

**키워드:** 정보 은닉, 데이터+메서드 묶음, 접근 제한

**한 줄 암기:**

> 캡슐화 = **묶고 숨김**
> 

---

## 2. 상속 (Inheritance)

**부모 클래스의 속성과 기능을 자식 클래스가 물려받는 것**

- 코드 재사용 가능
- 중복 코드 감소
- 확장성 향상

**키워드:** 부모/자식 클래스, 재사용, `extends`

**한 줄 암기:**

> 상속 = **물려받기**
> 

---

## 3. 다형성 (Polymorphism)

**하나의 이름(메서드)으로 여러 형태의 동작을 수행하는 것**

- 같은 이름, 다른 동작
- 오버로딩(Overloading)
- 오버라이딩(Overriding)

예: `sound()`

강아지 → 멍멍 / 고양이 → 야옹

**키워드:** 같은 이름, 다른 동작, 오버로딩, 오버라이딩

**한 줄 암기:**

> 다형성 = **같은 이름, 다른 동작**
> 

---

## 4. 추상화 (Abstraction)

**공통 특징과 핵심 기능만 단순화하여 표현하는 것**

- 불필요한 부분 숨김
- 핵심 기능만 표현
- 복잡한 시스템 단순화

예: 자동차 → 엔진 원리는 몰라도 브레이크/가속만 사용

**키워드:** 핵심만 표현, 공통 특징, 단순화

**한 줄 암기:**

> 추상화 = **핵심만 표현**
> 

---
