---
title: "0609 - 무결성 종류"
---

| 종류 | 뜻 | 핵심 암기 |
| --- | --- | --- |
| **개체 무결성** | 기본키는 `NULL`이면 안 되고, 중복되면 안 됨 | 기본키 = NULL X, 중복 X |
| **참조 무결성** | 외래키는 참조하는 테이블의 기본키 값과 맞아야 함 | 외래키 = 없는 값 참조 X |
| **도메인 무결성** | 속성 값은 정해진 범위/형식 안에 있어야 함 | 나이 = 숫자, 성별 = 정해진 값 |
| **사용자 정의 무결성** | 사용자가 정한 업무 규칙을 지켜야 함 | 점수는 0~100점 |
| **NULL 무결성** | 특정 속성은 NULL이 들어가면 안 됨 | 필수 입력 |
| **고유 무결성** | 특정 속성 값은 중복되면 안 됨 | 주민번호, 이메일 중복 X |
| **관계 무결성** | 릴레이션 간 관계가 논리적으로 맞아야 함 | 테이블 관계 오류 X |

시험에서는 보통 **개체 / 참조 / 도메인** 이 3개가 제일 중요함.
