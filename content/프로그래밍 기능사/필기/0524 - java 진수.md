> [!tip]
> **Java 진수(정수 리터럴) 표기**
>
> - **2진수**: `0b` 또는 `0B` (예: `0b1010`)
> - **8진수**: `0` (예: `012`)
> - **10진수**: 접두사 없음 (예: `10`)
> - **16진수**: `0x` 또는 `0X` (예: `0xA`)


### 간단 예시

- `0b1010` → 2진수 `1010` → **10**
- `012` → 8진수 `12` → **10**
- `10` → 10진수 `10` → **10**
- `0xA` → 16진수 `A` → **10**

```java
System.out.println(0b1010); // 10
System.out.println(012);    // 10
System.out.println(10);     // 10
System.out.println(0xA);    // 10
```

### 시험용 암기

```
0b = 2진수
0  = 8진수
없음 = 10진수
0x = 16진수
```

### 주의

```java
int a = 010;
System.out.println(a);
```

- 출력은 **10이 아니라 8**
- `010`은 10진수 10이 아니라 **8진수 10**
- **8진수 10 = 10진수 8**
