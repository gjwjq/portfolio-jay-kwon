## 데이터베이스 DB

| 키워드 | 정리 |
| --- | --- |
| 데이터베이스 | 관련 있는 데이터를 모아둔 것 |
| 목적 | 중복 줄이고, 여러 사람이 공유 |
| 특징 | 실시간 접근, 계속 변화, 동시 공유, 내용 기반 참조 |

---

## DBMS

| 키워드 | 정리 |
| --- | --- |
| DBMS | 데이터베이스 관리 시스템 |
| 역할 | 데이터 저장, 검색, 수정, 삭제 관리 |
| 예시 | Oracle, MySQL, MariaDB, SQL Server |
| 문제 포인트 | “데이터베이스를 관리하는 소프트웨어” → DBMS |

---

## 스키마 Schema

| 키워드 | 정리 |
| --- | --- |
| 스키마 | 데이터베이스의 구조 / 설계도 |
| 쉽게 | 테이블이 어떻게 생겼는지 정해둔 틀 |
| 예시 | 학생(학번, 이름, 학과) |
| 문제 포인트 | “구조와 제약조건 정의” → 스키마 |

---

## 인스턴스 Instance

| 키워드 | 정리 |
| --- | --- |
| 인스턴스 | 현재 실제로 들어있는 데이터 |
| 쉽게 | 테이블 안의 실제 행들 |
| 스키마와 차이 | 스키마는 틀, 인스턴스는 현재 내용 |

---

## 관계 데이터 모델

| 키워드 | 정리 |
| --- | --- |
| 관계 데이터 모델 | 데이터를 2차원 테이블 형태로 표현 |
| 릴레이션 | 테이블 |
| 튜플 | 행, 레코드 |
| 속성 | 열, 컬럼 |
| 도메인 | 속성이 가질 수 있는 값의 범위 |

**문제 문장:**

“데이터를 2차원 테이블 형태로 표현”

→ 관계 데이터 모델

---

## 데이터 모델 종류

| 데이터 모델 | 특징 |
| --- | --- |
| 계층 데이터 모델 | 트리 구조, 부모-자식 |
| 망 데이터 모델 | 그래프 구조, 다대다 표현 가능 |
| 관계 데이터 모델 | 2차원 테이블 |
| 객체지향 데이터 모델 | 객체 중심, 클래스/상속 개념 |
