## DB/SQL 핵심 연결표

| 파트 | 핵심 개념 | 한 줄 암기 |
| --- | --- | --- |
| UNION | 두 SELECT 결과 합침 | UNION / 합치기 / 중복 제거 |
| UNION ALL | 두 SELECT 결과 합침 | UNION ALL / 합치기 / 중복 포함 |
| INTERSECT | 공통 데이터 출력 | INTERSECT / 둘 다 있는 것만 |
| EXCEPT | 앞 결과에서 뒤 결과 제외 | EXCEPT / 앞에서 뒤를 뺌 |
| 시스템 카탈로그 | DB 구조 정보 저장 | 시스템 카탈로그 / 테이블 컬럼 인덱스 권한 정보 |
| ACID 원자성 | 모두 실행 또는 모두 취소 | 원자성 / All or Nothing |
| ACID 일관성 | 전후 상태 모순 없음 | 일관성 / 실행 전후 DB 상태 유지 |
| ACID 고립성 | 동시에 실행돼도 간섭 없음 | 고립성 / 트랜잭션끼리 간섭 X |
| ACID 지속성 | 완료 결과 영구 반영 | 지속성 / 커밋 결과는 저장됨 |
| RENAME | 테이블 이름 변경 | RENAME / 테이블 이름 바꾸기 |
| VIEW | SELECT 결과 가상 테이블 | VIEW / 보안성 편리성 제공 |
| VIEW 주의점 | 항상 수정 가능 아님 | VIEW / 삽입 삭제 갱신 제한될 수 있음 |
| 충돌 | 같은 데이터 동시 수정 문제 | 충돌 / 동시에 수정해서 결과 꼬임 |
| DBA | 데이터베이스 관리자 | DBA / 설계 권한 백업 복구 보안 성능 관리 |
| 백업 | 데이터 복사본 저장 | 백업 / 데이터 손실 대비 |
| 백업 용량 | 데이터 크기와 증가량 고려 | 백업 용량 / 크기 성장률 주기 보관 기간 |

## UI/UX 핵심 연결표

| 개념 | 의미 | 시험용 구분 |
| --- | --- | --- |
| UI | 사용자가 보는 화면 요소 | 버튼 / 메뉴 / 아이콘 / 입력창 |
| UX | 사용자가 느끼는 전체 경험 | 편리함 / 만족감 / 사용 흐름 |
| 사용성 | 쉽고 편하게 쓸 수 있는 정도 | 처음 써도 기능 찾기 쉬움 |
| 접근성 | 장애인도 사용할 수 있게 설계 | 화면 읽기 / 자막 / 키보드 조작 / 색 대비 |
| 반응성 | 입력에 빠르게 반응 | 버튼 누르면 바로 반응 |
| 일관성 | 화면과 조작 방식이 일정 | 저장 버튼 위치가 항상 같음 |
| 직관성 | 설명 없이 바로 이해 가능 | 돋보기 = 검색 / 휴지통 = 삭제 |
| 가독성 | 글자와 정보가 읽기 쉬움 | 글자 크기 / 색 대비 / 문단 간격 |
