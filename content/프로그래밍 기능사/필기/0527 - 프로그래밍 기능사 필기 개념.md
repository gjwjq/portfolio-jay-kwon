## JavaScript 배열 메서드

| 개념 | 알기문장 |
| --- | --- |
| `pop()` | 배열의 **맨 끝 값 삭제** |
| `join()` | 배열 요소들을 **문자열 하나로 합침** |
| `slice()` | 배열에서 **정한 범위만 가져옴** |
| `splice()` | 배열의 **원본을 직접 변경** |
| `length` | 배열의 **길이/개수** |

**암기**

범위 가져오기 = `slice`

원본 변경 = `splice`

## SQL 컬럼 변경

| 개념 | 알기문장 |
| --- | --- |
| `ADD` | 새로운 컬럼을 **추가** |
| `MODIFY` | 기존 컬럼의 타입/크기/기본값을 **수정** |
| `ALTER` | 테이블 구조를 바꾸는 **큰 명령어** |
| `PLUS` | SQL 구조 변경 명령어 아님 |

**암기**

ADD = 추가

MODIFY = 기존 것 수정

ALTER TABLE MODIFY = 테이블 컬럼 수정

## JOIN

| 개념 | 알기문장 |
| --- | --- |
| INNER JOIN | 양쪽 테이블에 **공통으로 있는 데이터만** 가져옴 |
| LEFT OUTER JOIN | 왼쪽 테이블은 전부, 오른쪽은 **매칭되는 것만** 가져옴 |
| RIGHT OUTER JOIN | 오른쪽 테이블은 전부, 왼쪽은 **매칭되는 것만** 가져옴 |
| OUTER JOIN | 한쪽에만 있는 데이터도 포함 가능 |

**암기**

LEFT OUTER JOIN = 왼쪽 전부 + 오른쪽 매칭값

INNER JOIN = 공통 부분만

이상 현상 3개 = 삽입 / 삭제 / 갱신

## 자료구조

| 개념 | 알기문장 |
| --- | --- |
| 선형 구조 | 데이터가 **줄처럼 1자로 연결**된 구조 |
| 비선형 구조 | 데이터가 **가지치기/그물처럼 연결**된 구조 |
| 스택 | 나중에 들어온 것이 먼저 나감, LIFO |
| 큐 | 먼저 들어온 것이 먼저 나감, FIFO |
| 데크 | 양쪽에서 삽입/삭제 가능 |
| 트리 | 계층 구조, 비선형 |
| 그래프 | 정점과 간선으로 연결, 비선형 |

**암기**

스택 = 접시 쌓기 = LIFO

큐 = 줄 서기 = FIFO

트리/그래프 = 비선형 구조

## 데이터베이스 Key

| 개념 | 알기문장 |
| --- | --- |
| 슈퍼키 | 튜플을 유일하게 구분할 수 있는 속성 집합 |
| 후보키 | 슈퍼키 중 최소성을 만족하는 키 |
| 기본키 | 후보키 중 대표로 선택한 키 |
| 대체키 | 후보키 중 기본키로 선택되지 않은 키 |

**암기**

후보키 = 유일성 O + 최소성 O

기본키 = 대표 후보키

대체키 = 탈락한 후보키

외래키 = 다른 테이블 기본키 참조

## 무결성 제약 조건

| 개념 | 알기문장 |
| --- | --- |
| 개체 무결성 | 기본키는 NULL, 중복 불가 |
| 참조 무결성 | 외래키는 참조할 수 없는 값을 가질 수 없음 |
| 도메인 무결성 | 속성 값은 정해진 범위/형식만 가능 |

**암기**

기본키 NULL/중복 불가 = 개체 무결성

없는 외래키 값 불가 = 참조 무결성

정해진 값만 입력 = 도메인 무결성

## 애플리케이션 테스트

| 개념 | 알기문장 |
| --- | --- |
| 테스트 케이스 | 입력값, 실행 조건, 기대 결과를 정리한 테스트 명세서 |
| 워크스루 | 개발자가 모여 산출물을 검토하는 회의 |
| 인스펙션 | 정해진 절차에 따라 공식적으로 검토 |
| 살충제 패러독스 | 같은 테스트만 반복하면 새 오류를 못 찾는 현상 |

**암기**

입력값 + 실행 조건 + 기대 결과 = 테스트 케이스

검토 회의 = 워크스루

공식 검토 = 인스펙션

같은 테스트 반복 = 살충제 패러독스
