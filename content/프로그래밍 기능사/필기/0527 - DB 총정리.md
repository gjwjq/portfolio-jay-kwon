# DB 초압축 정리

## DB 기본

- **스키마**: DB의 구조와 제약조건을 적은 설계도
- **릴레이션**: 테이블 전체
- **튜플**: 행, 레코드
- **속성**: 열, 필드
- **도메인**: 속성이 가질 수 있는 값의 범위
- **차수(degree)**: 열 개수
- **카디널리티**: 행 개수

## 키

- **기본키**: 대표 키, 중복 X, NULL X
- **후보키**: 기본키가 될 수 있는 키
- **대체키**: 후보키 중 기본키로 선택 안 된 키
- **외래키**: 다른 테이블의 기본키를 참조하는 키
- **슈퍼키**: 튜플을 유일하게 구분 가능한 키 조합

## 무결성

- **개체 무결성**: 기본키는 NULL/중복 불가
- **참조 무결성**: 외래키는 참조하는 값이 실제로 있어야 함
- **도메인 무결성**: 정해진 값의 범위만 입력 가능

## 관계대수

- **σ**: SELECT, 조건에 맞는 행 선택
- **π**: PROJECT, 원하는 열 선택
- **∪**: 합집합
- **∩**: 교집합
- **－**: 차집합
- **×**: 모든 조합

## SQL

- **SELECT**: 조회할 열
- **FROM**: 사용할 테이블
- **WHERE**: 조건

## LIKE

- **%**: 글자 수 상관없음
- **_**: 한 글자

예시:

- `_s%`: 두 번째 글자가 s
- `__s%`: 세 번째 글자가 s

## JOIN

- **JOIN**: 두 테이블을 연결해서 조회
- `FROM A, B WHERE A.코드 = B.코드` 도 조인 방식임
