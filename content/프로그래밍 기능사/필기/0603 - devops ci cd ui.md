## DevOps

| 키워드 | 정리 |
| --- | --- |
| DevOps | Development + Operations |
| 의미 | 개발팀과 운영팀이 협력하여 빠르게 개발/배포하는 방식 |
| 목적 | 자동화, 빠른 배포, 안정적인 운영 |
| 문제 포인트 | 개발과 운영의 통합 |

---

## CI / CD

| 용어 | 의미 |
| --- | --- |
| CI | Continuous Integration, 지속적 통합 |
| CD | Continuous Delivery 또는 Continuous Deployment, 지속적 제공/배포 |

### CI

| 키워드 | 정리 |
| --- | --- |
| CI | 코드를 자주 합치고 자동 테스트 |
| 목적 | 오류를 빨리 발견 |

### CD

| 키워드 | 정리 |
| --- | --- |
| CD | 배포 과정을 자동화 |
| Delivery | 배포 준비까지 자동화 |
| Deployment | 실제 배포까지 자동화 |

**외우기:**

CI = 코드 합치고 테스트

CD = 배포 자동화

---

## UI

| 키워드 | 정리 |
| --- | --- |
| UI | User Interface |
| 의미 | 사용자가 시스템과 만나는 화면/조작 부분 |
| 예시 | 버튼, 메뉴, 아이콘, 입력창 |

---

## UX

| 키워드 | 정리 |
| --- | --- |
| UX | User Experience |
| 의미 | 사용자가 서비스를 이용하면서 느끼는 전체 경험 |
| 예시 | 편리함, 만족감, 접근성 |

**차이:**

UI = 눈에 보이는 화면

UX = 사용하면서 느끼는 경험

---

## UI 설계 원칙

| 원칙 | 의미 |
| --- | --- |
| 직관성 | 보고 바로 이해 가능 |
| 유효성 | 사용자의 목적을 정확히 달성 |
| 학습성 | 쉽게 배울 수 있음 |
| 유연성 | 사용자의 요구를 잘 수용 |

**외우기:**

직유학유

= 직관성, 유효성, 학습성, 유연성

---

## UI 종류

| 종류 | 정리 |
| --- | --- |
| CLI | 명령어 입력 방식 |
| GUI | 그래픽 화면 방식 |
| NUI | 터치, 음성, 동작 등 자연스러운 방식 |
| VUI | 음성 기반 인터페이스 |
| OUI | 사물 기반 인터페이스 |
