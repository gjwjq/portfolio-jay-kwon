## 1. DB 이상 현상

이상 현상은 테이블 설계가 잘못되어 데이터가 중복될 때 발생하는 문제이다.

주로 `삽입 이상`, `삭제 이상`, `갱신 이상`이 나온다.

| 이상 현상 | 의미 |
| --- | --- |
| 삽입 이상 | 데이터를 추가하려면 불필요한 정보까지 넣어야 하는 문제 |
| 삭제 이상 | 데이터를 삭제했더니 필요한 정보까지 같이 사라지는 문제 |
| 갱신 이상 | 일부 데이터만 수정되어 서로 불일치하는 문제 |

## 갱신 이상

문제에서 말한

**“데이터 중복으로 인해 일부만 수정되어 데이터 간 불일치가 발생하는 현상”**

은 `갱신 이상`이다.

예시:

| 학생 | 학과 | 학과실 |
| --- | --- | --- |
| 철수 | 컴퓨터과 | 301호 |
| 영희 | 컴퓨터과 | 301호 |

컴퓨터과 학과실이 `302호`로 바뀌었는데 철수 행만 수정하면?

| 학생 | 학과 | 학과실 |
| --- | --- | --- |
| 철수 | 컴퓨터과 | 302호 |
| 영희 | 컴퓨터과 | 301호 |

같은 컴퓨터과인데 학과실 정보가 다르다.

이게 `갱신 이상`이다.

### 헷갈리는 보기 정리

| 보기 | 정리 |
| --- | --- |
| 삽입 이상 | 추가할 때 문제 |
| 삭제 이상 | 삭제할 때 필요한 정보까지 사라짐 |
| 갱신 이상 | 수정할 때 일부만 바뀌어 불일치 |
| 불일치 이상 | 보통 정식 3대 이상 현상으로 보지는 않음 |

### 핵심 암기

> 삽입 = 추가 문제
> 
> 
> 삭제 = 같이 사라짐
> 
> 갱신 = 일부만 수정되어 불일치
>

## 2. UI 사용성 평가와 소프트웨어 품질

UI 관련 문제에서는 `학습성`, `기억용이성`, `오류`, `효율성`, `만족도` 같은 개념이 나온다.

## UI 사용성 평가 항목

| 항목 | 의미 |
| --- | --- |
| 학습성 | 처음 사용하는 사람이 쉽게 배울 수 있는가 |
| 기억용이성 | 오랜만에 다시 사용해도 기억하기 쉬운가 |
| 오류 | 사용 중 오류가 적고 복구가 쉬운가 |
| 효율성 | 사용자가 빠르고 편하게 작업할 수 있는가 |
| 만족도 | 사용자가 사용하면서 만족하는가 |

UI 사용성은 결국 **사람이 쓰기 쉬운가**를 평가하는 것이다.

## 이식성

`이식성`은 UI 사용성 평가 항목이라기보다는 **소프트웨어 품질 특성**이다.

| 개념 | 의미 |
| --- | --- |
| 이식성 | 다른 운영체제, 하드웨어, 브라우저, DB 환경에서도 실행 가능한 능력 |

예를 들어 어떤 프로그램이 Windows에서도 되고, Linux에서도 되고, Mac에서도 잘 돌아가면 이식성이 높다고 볼 수 있다.

### 헷갈리는 보기 정리

| 보기 | 사용성 평가 여부 |
| --- | --- |
| 학습성 | UI 사용성 평가 항목 |
| 기억용이성 | UI 사용성 평가 항목 |
| 오류 | UI 사용성 평가 항목 |
| 이식성 | 사용성보다는 소프트웨어 품질 특성 |

### 핵심 암기

> UI 사용성 = 사람이 쓰기 쉬운가
> 
> 
> 이식성 = 다른 환경에서도 잘 돌아가는가
>

## 3. 백업 시스템

백업은 데이터를 잃어버렸을 때 복구하기 위해 미리 저장해 두는 것이다.

문제에서는 `하이브리드 백업` 개념이 중요하다.

## 백업 방식

| 방식 | 의미 |
| --- | --- |
| 온프레미스 백업 | 회사 내부 서버나 저장장치에 백업 |
| 클라우드 백업 | 인터넷 기반 클라우드 서버에 백업 |
| 하이브리드 백업 | 온프레미스와 클라우드를 함께 사용하는 방식 |

## 하이브리드 백업

하이브리드 백업은 내부 저장소와 클라우드를 함께 사용한다.

| 장점 | 설명 |
| --- | --- |
| 빠른 복구 | 내부 저장소에서 빠르게 복구 가능 |
| 안정성 | 내부 장비가 고장 나도 클라우드 백업이 있음 |
| 유연성 | 상황에 따라 내부/외부 저장소를 같이 활용 가능 |

### 헷갈리는 보기 정리

| 보기 내용 | 판단 |
| --- | --- |
| 온프레미스와 클라우드를 결합 | 하이브리드 백업의 핵심 설명 |
| 관리가 단순하고 소규모 기업에만 적합 | 일반적인 하이브리드 백업 설명으로는 애매함 |
| 클라우드만 사용 | 하이브리드 아님 |
| 내부 저장소만 사용 | 하이브리드 아님 |

### 주의

사진 속 문제는 정답 표시가 애매해 보인다.

일반적인 개념 기준으로는 **하이브리드 백업 = 온프레미스 + 클라우드 결합**으로 외우는 게 맞다.

### 핵심 암기

> 하이브리드 = 섞은 것
> 
> 
> 하이브리드 백업 = 내부 저장소 + 클라우드
>
