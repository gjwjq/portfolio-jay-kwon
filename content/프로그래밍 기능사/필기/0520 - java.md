### substring() 요약

- **문자열에서 일부를 잘라 새 문자열로 반환**합니다.
- 원본 문자열은 바뀌지 않습니다.
- 자바에서는 인덱스가 **0부터 시작**합니다.
- 주로 사용 형태
    - `substring(beginIndex)` : beginIndex부터 끝까지
    - `substring(beginIndex, endIndex)` : beginIndex부터 **endIndex 직전**까지

**예시**

```java
String s = "HelloWorld";
System.out.println(s.substring(5));     // "World"
System.out.println(s.substring(0, 5));  // "Hello"
```

### equals() vs equalsIgnoreCase() 요약

- `equals()`
    - **대소문자를 구분**해서 문자열이 같은지 비교합니다.
- `equalsIgnoreCase()`
    - **대소문자를 무시**하고 문자열이 같은지 비교합니다.

**예시**

```java
String a = "Java";
String b = "java";

System.out.println(a.equals(b));            // false
System.out.println(a.equalsIgnoreCase(b));  // true
```

---

### 같이 쓰는 예시

```java
String email = "User@Example.com";
String domain = email.substring(email.indexOf('@') + 1); // "Example.com"

if (domain.equalsIgnoreCase("example.com")) {
	System.out.println("허용 도메인");
}
```

> [!tip]
> `==` 는 문자열 내용 비교가 아니라 **참조(주소) 비교**라서, 문자열 비교는 보통 `equals()`를 사용합니다.
