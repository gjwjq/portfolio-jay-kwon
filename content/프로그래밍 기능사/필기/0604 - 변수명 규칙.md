## 언어별 변수명 규칙

| 언어 | 사용 가능 문자 | 숫자 시작 | 예약어 | 특징 |
| --- | --- | --- | --- | --- |
| C언어 | 영문자, 숫자, `_` | 불가능 | 불가능 | 대소문자 구분 |
| Java | 영문자, 숫자, `_`, `$` | 불가능 | 불가능 | 대소문자 구분 |
| Python | 영문자, 숫자, `_` | 불가능 | 불가능 | 대소문자 구분 |

## 공통 규칙

| 조건 | 설명 | 예시 |
| --- | --- | --- |
| 숫자로 시작 X | 변수명 첫 글자는 숫자가 될 수 없음 | `1score` 불가능 |
| 예약어 사용 X | 언어에서 이미 정해진 단어는 사용 불가 | `int`, `class`, `for` 불가능 |
| 특수문자 사용 X | `-`, `@`, `#`, 공백 등 사용 불가 | `user-name` 불가능 |
| 대소문자 구분 | `age`와 `Age`는 다른 변수 | `score`, `Score` 다름 |
| 의미 있게 작성 | 변수의 역할이 보이게 작성 | `a`보다 `studentScore`가 좋음 |

## 가능한 변수명

```
age
score
score1
student_name
userAge
_total
```

---

## 불가능한 변수명

```
1score      → 숫자로 시작해서 불가능
user-name   → - 특수문자 사용해서 불가능
student name → 공백이 있어서 불가능
class       → 예약어라서 불가능
int         → 예약어라서 불가능
score!      → ! 특수문자 사용해서 불가능
```

---

## 예약어란?

| 개념 | 설명 |
| --- | --- |
| 예약어 | 프로그래밍 언어에서 이미 문법용으로 정해놓은 단어 |
| 사용 불가 이유 | 컴퓨터가 변수명인지 문법인지 헷갈리기 때문 |

예시:

```
int, class, for, if, while, return
```

---

## 시험용 암기

```
변수명은 문자나 _로 시작하고, 숫자로 시작할 수 없으며, 예약어와 특수문자는 사용할 수 없다.
```

```
C / Java / Python 모두 변수명은 대소문자를 구분한다.
```

```
Java는 변수명에 $도 가능하지만, 시험에서는 문자·숫자·_ 중심으로 외우면 된다.
```
