## 프로그래밍 방식

| 구분 | 핵심 | 특징 | 지양/주의 |
| --- | --- | --- | --- |
| 구조적 프로그래밍 | 순차/선택/반복 | Top-Down, 모듈화, 유지보수 쉬움 | GOTO 사용 X |
| 객체지향 프로그래밍 | 객체 중심 | 캡슐화, 상속, 다형성, 추상화 | 절차 중심 X |
| 절차적 프로그래밍 | 순서 중심 | 위에서 아래로 순서대로 실행 | 객체 중심 X |

**외우기:**

구조적 = 순차 / 선택 / 반복 / GOTO X

객체지향 = 캡슐화 / 상속 / 다형성 / 추상화

## 객체지향 기본 개념

| 개념 | 의미 |
| --- | --- |
| 클래스 | 객체를 만들기 위한 설계도 |
| 객체 | 실제로 만들어진 대상 |
| 속성 | 객체가 가진 데이터 |

**외우기:**

클래스 = 설계도

객체 = 실체

속성 = 데이터

메서드 = 동작

캡슐화 = 정보 은닉

## Python list 정렬

## 표기법

| 표기법 | 특징 | 예시 |
| --- | --- | --- |
| 헝가리안 표기법 | 변수명에 자료형 표시 | `strName`, `intAge` |
| 카멜 표기법 | 두 번째 단어부터 대문자 | `studentName` |
| 파스칼 표기법 | 모든 단어 첫 글자 대문자 | `StudentName` |
| 스네이크 표기법 | `_`로 연결 | `student_name` |

**외우기:**

헝가리안 = 자료형 표시

카멜 = 중간 대문자

파스칼 = 처음도 대문자

스네이크 = 밑줄

## try-catch 예외 처리

| 구문 | 의미 |
| --- | --- |
| try | 오류가 날 수 있는 코드 |
| catch | 오류 발생 시 처리 |
| finally | 오류 여부와 상관없이 실행 |
| Exception | 예외, 오류 상황 |

**실행 순서:**

| 상황 | 순서 |
| --- | --- |
| 오류 없음 | try → finally |
| 오류 있음 | try → catch → finally |

**외우기:**

try = 시도

catch = 오류 잡기

finally = 무조건 실행
