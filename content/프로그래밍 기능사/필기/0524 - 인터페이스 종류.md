---
title: "0524 - 인터페이스 종류"
---

CLI

- 명령어 입력 방식
- 키보드로 명령어 직접 입력
- 예) CMD, 터미널
- 암기) **Command = 명령어**

GUI

- 그래픽 화면 방식
- 마우스로 아이콘/버튼 클릭
- 예) 윈도우 화면, 폴더, 아이콘
- 암기) **Graphic = 그림 화면**

NUI

- 자연스러운 인터페이스 방식
- 터치, 음성, 제스처 사용
- 예) 스마트폰 터치, 음성인식, 모션 인식
- 암기) **Natural = 자연스러움**

OUI

- 유기적 인터페이스 방식
- 사물·환경과 상호작용
- 예) 웨어러블 기기, 스마트 사물, 휘어지는 디스플레이
- 암기) **Organic = 유기적**

한 줄 핵심 암기

- CLI = 명령어 입력
- GUI = 마우스/아이콘
- NUI = 터치/음성/제스처
- OUI = 사물/환경 상호작용
