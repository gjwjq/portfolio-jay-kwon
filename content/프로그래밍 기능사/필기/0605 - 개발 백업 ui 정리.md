## CI / CD

| 개념 | 의미 |
| --- | --- |
| CI | 지속적 통합 |
| CD | 지속적 배포/전달 |

| 구분 | 핵심 |
| --- | --- |
| CI | 자동 빌드 + 자동 테스트 |
| CD | 자동 배포 |

**외우기:**

CI = 테스트까지

CD = 배포까지

---

## 백업 운영 방식

| 방식 | 의미 |
| --- | --- |
| 자체 운영 | 기업이 직접 백업 센터 운영 |
| 공동 운영 | 여러 기업이 공동으로 운영 |
| 상호 계약 | 기업끼리 미리 계약 후 서로 지원 |
| 전문 업체 위탁 | 복구 전문 업체에 맡김 |

**외우기:**

상호 계약 = 서로 도와주기로 미리 약속

---

## UI

| 특징 | 의미 |
| --- | --- |
| 편의성 | 사용하기 쉬움 |
| 오류 최소화 | 실수를 줄임 |
| 구체적 방법 제공 | 사용 방법을 알려줌 |
| 사용자 중심 | 사용자가 쉽게 상호작용 |

### UI 특징 아님

| 아님 | 이유 |
| --- | --- |
| 작업 시간 증가 | 좋은 UI는 작업 시간을 줄여야 함 |

**외우기:**

UI = 편의성 증가, 오류 감소, 작업 시간 감소
