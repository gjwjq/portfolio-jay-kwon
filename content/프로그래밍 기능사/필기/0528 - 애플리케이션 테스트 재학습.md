## 2) 애플리케이션 테스트 기본 원리

> 여기는 **문장 키워드 그대로** 외우면 됨.
> 

| 답 / 개념 | 나오는 키워드 |
| --- | --- |
| 완벽한 테스트 불가능 | 결함을 줄일 수는 있지만 결함이 없다고 증명 불가 |
| 파레토 법칙 | 20% 코드에서 80% 결함 |
| 살충제 패러독스 | 같은 테스트 케이스 반복, 새로운 결함 발견 어려움 |
| 결함 집중 | 소수 특정 모듈에 결함 집중 |
| 오류-부재의 궤변 | 오류가 없어도 요구사항 불만족이면 품질 낮음 |
| 테스트와 위험 | 테스트 많이 하면 미래 위험 감소 |

| 독립적 테스트 | 개발자와 관계없는 별도 팀이 수행 |
