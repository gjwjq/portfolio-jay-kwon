## 커널

커널은 **운영체제의 핵심 부분**이다.

운영체제에서 가장 중요한 기능을 담당하며, 컴퓨터 자원을 관리한다.

## 커널의 역할

| 역할 | 의미 |
| --- | --- |
| 프로세스 관리 | 실행 중인 프로그램 관리 |
| CPU 관리 | CPU를 어떤 작업에 줄지 제어 |
| 메모리 관리 | 프로그램에 메모리 할당 |
| 파일 시스템 관리 | 파일 저장과 접근 관리 |
| 입출력 장치 관리 | 키보드, 마우스, 프린터 등 제어 |
| 시스템 자원 관리 | CPU, 메모리, 장치 전체 관리 |

## 커널이 직접 수행하는 기능

```
메모리 관리 / 프로세스 관리 / CPU 관리 / 파일 시스템 관리 / 입출력 장치 관리
```

## 커널이 직접 하는 것으로 보기 어려운 것

```
사용자 인터페이스 제공 / 응용 프로그램 화면 출력 / 인터넷 파일 전송 처리 / 하드웨어 제조
```

## 핵심 암기

커널 / 운영체제 핵심 / 자원 관리 / 시스템 제어

---

## 운영체제의 주요 목적

운영체제는 **컴퓨터 자원을 효율적으로 관리하고 사용자와 하드웨어 사이를 중재하는 시스템 소프트웨어**이다.

## 운영체제 역할

| 역할 | 의미 |
| --- | --- |
| 하드웨어 자원 관리 | CPU, 메모리, 저장장치 관리 |
| 사용자와 하드웨어 사이 중재 | 사용자가 하드웨어를 쉽게 사용하게 함 |
| 여러 작업 동시 처리 | 멀티태스킹 지원 |
| 시스템 안정성 제공 | 오류와 충돌 감소 |
| 자원 효율적 사용 | 컴퓨터 성능 낭비 방지 |

## 운영체제 목적이 아닌 것

```
데이터베이스 설계
```

DB 설계는 운영체제가 아니라 DBA나 개발자가 담당한다.

## 핵심 암기

운영체제 / 자원 관리 / 사용자와 하드웨어 중재 / 여러 작업 처리

---

## 입출력 장치 관리

입출력 장치 관리는 **사용자와 하드웨어 사이의 데이터 송수신을 제어하는 역할**이다.

예시:

```
키보드 입력 / 마우스 입력 / 모니터 출력 / 프린터 출력 / USB 장치 관리
```

## 핵심 암기

입출력 장치 관리 / 하드웨어와 사용자 간 데이터 송수신 제어
