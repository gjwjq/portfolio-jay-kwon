## 프로세스 / 스케줄링

| 개념 | 의미 |
| --- | --- |
| 프로그램 | 실행 전 파일 |
| 프로세스 | 실행 중인 프로그램 |
| 스케줄링 | CPU를 어떤 프로세스에 줄지 결정 |

**외우기:**

프로세스 = 실행 중

스케줄링 = CPU 배정

## 로더 Loader

| 기능 | 의미 |
| --- | --- |
| 할당 | 메모리 공간 확보 |
| 연결 | 여러 프로그램 조각 연결 |

| 적재 | 메모리에 올림 |

### 로더 기능 아님

| 아님 | 이유 |
| --- | --- |
| 스케줄링 | CPU 배정 기능 |

**외우기:**

로더 = 할당 / 연결 / 재배치 / 적재

스케줄링은 로더 아님

## MS-DOS 명령어

| 명령어 | 의미 |
| --- | --- |
| DIR | 파일 목록 보기 |
| COPY | 복사 |
| DEL | 삭제 |
| REN | 이름 변경 |
| CD | 디렉터리 이동 |
| MORE | 한 화면씩 출력 |
| FORMAT | 디스크 초기화 |
| CHKDSK | 디스크 검사 |
| BACKUP | 백업 |
| RESTORE | 복구 |

## 내부 명령어 / 외부 명령어

| 구분 | 예시 |
| --- | --- |
| 내부 명령어 | DIR, COPY, DEL, CD |
| 외부 명령어 | FORMAT, CHKDSK, BACKUP, RESTORE |

DIR / COPY / DEL / CD = 내부

FORMAT / CHKDSK / BACKUP / RESTORE = 외부

## TCP / UDP

| 구분 | TCP | UDP |
| --- | --- | --- |
| 연결 | 연결형 | 비연결형 |
| 신뢰성 | 높음 | 낮음 |
| 속도 | 느림 | 빠름 |
| 예시 | 정확한 전송 | 빠른 전송 |

**외우기:**

TCP = 신뢰성

UDP = 빠름, 신뢰성 낮음

---

## IPv6 주소 방식

| 방식 | 의미 |
| --- | --- |
| Unicast | 1대1 |
| Multicast | 1대다 그룹 |
| Anycast | 가장 가까운 하나 |

### IPv6에 없는 것

| 없음 | 정리 |
| --- | --- |
| Broadcast | IPv6에서는 사용하지 않음 |

**외우기:**

IPv6 = Broadcast 없음
