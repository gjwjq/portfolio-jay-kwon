### 1. switch

- **if문과 비슷하지만, 값이 딱 떨어지는 경우에 사용**
- `break`가 없으면 아래 `case`까지 **연속 실행(fall-through)** 되므로 보통 각 `case` 끝에 넣어줌

```java
int score = 2;

switch (score) {
	case 1:
		System.out.println("1등");
		break;
	case 2:
		System.out.println("2등");
		break;
	default:
		System.out.println("꼴등");
}
```

### 2. for / while / break / continue

- **for**: 몇 번 반복할지 알 때

```java
for (int i = 0; i < 5; i++) {
	System.out.println(i); // 0 1 2 3 4
}
```

- **while**: 조건이 `true`인 동안 반복

```java
int i = 0;
while (i < 5) {
	System.out.println(i);
	i++;
}
```

- **break**: 반복문 즉시 탈출

```java
for (int i = 0; i < 5; i++) {
	if (i == 3) break;
	System.out.println(i); // 0 1 2
}
```

- **continue**: 이번 회차만 건너뜀

```java
for (int i = 0; i < 5; i++) {
	if (i == 3) continue;
	System.out.println(i); // 0 1 2 4
}
```

### 3. 배열

- 인덱스는 **0부터 시작**
- `arr[5]`처럼 범위를 벗어나면 오류

```java
// 선언
int[] arr = {10, 20, 30, 40, 50};

// 인덱스로 접근 (0부터 시작)
System.out.println(arr[0]); // 10
System.out.println(arr[2]); // 30

// 반복문으로 순회
for (int i = 0; i < arr.length; i++) {
	System.out.println(arr[i]);
}
```

### 4. getter / setter

- 변수를 `private`으로 막아두고, **값을 꺼내거나(getter) 바꾸는(setter) 메서드**

```java
class Person {
	private String name; // 외부에서 직접 접근 불가

	// getter: 값 꺼내기
	public String getName() {
		return name;
	}

	// setter: 값 바꾸기
	public void setName(String name) {
		this.name = name;
	}
}

// 사용
Person p = new Person();
p.setName("제이");
System.out.println(p.getName()); // 제이
```

### 5. enum

- 정해진 값들을 **상수로 묶어놓는 것**
- 오타 방지에 도움

```java
enum Day {
	MON, TUE, WED, THU, FRI, SAT, SUN
}

Day today = Day.MON;

if (today == Day.MON) {
	System.out.println("월요일");
}
```

- 그냥 **"정해진 선택지 목록"**이라고 생각하면 됨
