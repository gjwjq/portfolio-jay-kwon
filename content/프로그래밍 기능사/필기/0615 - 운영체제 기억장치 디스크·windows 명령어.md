## 1. 운영체제 스케줄링

스케줄링은 운영체제가 여러 프로세스 중에서 **CPU를 누구에게 줄지 결정하는 것**이다.

## 라운드 로빈 Round Robin

라운드 로빈은 각 프로세스에게 정해진 시간만큼 CPU를 나눠 주는 방식이다.

| 개념 | 의미 |
| --- | --- |
| 라운드 로빈 | CPU를 일정 시간씩 돌아가며 배정 |
| Time Quantum | 한 번에 CPU를 사용할 수 있는 정해진 시간 |
| 선점형 | 시간이 끝나면 CPU를 빼앗아 다음 프로세스에게 넘김 |
| 시분할 시스템 | 여러 사용자가 동시에 사용하는 것처럼 보이게 하는 시스템 |

예시:

| 순서 | 실행 |
| --- | --- |
| 1 | A 프로세스 2초 실행 |
| 2 | B 프로세스 2초 실행 |
| 3 | C 프로세스 2초 실행 |
| 4 | 다시 A 프로세스 2초 실행 |

## 다른 처리 방식

| 개념 | 의미 |
| --- | --- |
| 병렬 처리 | 여러 CPU나 코어가 동시에 작업 처리 |
| 실시간 처리 | 입력된 자료를 즉시 처리 |
| 분산 처리 | 여러 컴퓨터가 네트워크로 연결되어 작업 분담 |
| 시분할 처리 | CPU 시간을 잘게 나누어 여러 작업이 동시에 되는 것처럼 처리 |

### 핵심 암기

> 라운드 로빈 = 시간 조각만큼 돌아가며 CPU 사용
> 
> 
> Time Quantum 나오면 라운드 로빈
>

## 2. 기억장치 계층 구조

기억장치는 CPU와 가까울수록 빠르고 비싸다.

속도 순서가 자주 나온다.

## 빠른 순서

> 레지스터 → 캐시메모리 → RAM → 보조기억장치
> 

| 기억장치 | 의미 |
| --- | --- |
| 레지스터 | CPU 내부에 있는 가장 빠른 저장 공간 |
| 캐시메모리 | CPU와 RAM 사이의 속도 차이를 줄이는 고속 기억장치 |
| RAM | 실행 중인 프로그램과 데이터를 저장하는 주기억장치 |
| 보조기억장치 | SSD, HDD처럼 데이터를 오래 저장하는 장치 |

### 특징 정리

| 구분 | 속도 | 용량 | 가격 |
| --- | --- | --- | --- |
| 레지스터 | 가장 빠름 | 가장 작음 | 가장 비쌈 |
| 캐시 | 매우 빠름 | 작음 | 비쌈 |
| RAM | 빠름 | 중간 | 중간 |
| 보조기억장치 | 느림 | 큼 | 저렴 |

### 핵심 암기

> 레캐램보
> 
> 
> CPU 가까울수록 빠르고, 멀수록 용량이 큼
>

## 3. 디스크 관리와 Windows 명령어

## 디스크 조각 모음

디스크 조각 모음은 흩어진 파일 조각을 정리해서 **파일 접근 속도와 디스크 효율을 높이는 작업**이다.

| 개념 | 의미 |
| --- | --- |
| 단편화 | 파일이 디스크 여러 곳에 흩어져 저장된 상태 |
| 조각 모음 | 흩어진 파일 조각을 모아 정리하는 작업 |
| 목적 | 디스크 접근 속도 향상, 저장 공간 효율 개선 |

### 틀린 보기 주의

`불량 섹터를 치료한다`는 설명은 조각 모음이 아니다.

| 개념 | 의미 |
| --- | --- |
| 디스크 조각 모음 | 흩어진 파일 조각 정리 |
| 디스크 검사 | 오류 검사, 불량 섹터 확인 |
| 불량 섹터 | 디스크에서 손상된 저장 구역 |

### 핵심 암기

> 조각 모음 = 흩어진 파일 정리
> 
> 
> 불량 섹터 = 디스크 검사 쪽 개념
>

## DIR 명령어

`DIR`은 Windows 명령 프롬프트에서 파일과 폴더 목록을 보여주는 명령어이다.

| 명령어 | 의미 |
| --- | --- |
| `DIR` | 현재 폴더의 파일/폴더 목록 출력 |
| `DIR /P` | 한 화면씩 끊어서 출력 |
| `DIR /W` | 가로로 넓게 출력 |
| `DIR /S` | 하위 디렉터리까지 모두 출력 |
| `DIR /A` | 숨김 파일 등 특정 속성 파일도 출력 |

문제에서 **하위 디렉터리 정보까지 표시**하라고 하면 `DIR /S`이다.

### 핵심 암기

> `/S = Subdirectory = 하위 폴더까지`
>
