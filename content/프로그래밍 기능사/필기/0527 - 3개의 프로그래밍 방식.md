### 1. 구조적 프로그래밍

```
구조적 = 구조를 깔끔하게 만드는 방식
```

외울 키워드:

```
순차 / 조건 / 반복
Top-Down
모듈화
goto 지양
```

시험 함정:

```
goto 적극 활용 → 틀림
```

한 줄 암기:

```
구조적은 순조건반 + 탑다운 + 모듈화, goto는 싫어함
```

---

### 2. 절차적 프로그래밍

```
절차적 = 순서대로 처리하는 방식
```

외울 키워드:

```
입력 → 처리 → 출력
순서 중심
함수 중심
C언어
```

시험 함정:

```
객체 중심 → 절차적 아님
```

한 줄 암기:

```
절차적은 순서대로 함수 써서 처리, 대표는 C언어
```

---

### 3. 객체지향 프로그래밍

```
객체지향 = 객체 중심으로 만드는 방식
```

외울 키워드:

```
클래스 / 객체
캡슐화 / 상속 / 다형성 / 추상화
Java, C++
```

4대 특징 암기:

```
캡상다추
```

뜻:

```
캡슐화 = 데이터 + 기능 묶기
상속 = 부모 기능 물려받기
다형성 = 같은 이름, 다른 기능
추상화 = 중요한 것만 뽑기
```

한 줄 암기:

```
객체지향은 클래스와 객체, 특징은 캡상다추
```

---

## 진짜 최종 암기표

```
구조적 프로그래밍
= 순차/조건/반복, Top-Down, 모듈화, goto 지양

절차적 프로그래밍
= 순서대로 처리, 함수 중심, C언어

객체지향 프로그래밍
= 클래스/객체, 캡슐화/상속/다형성/추상화
```

## 헷갈릴 때 구분법

```
순차 조건 반복 → 구조적
입력 처리 출력, C언어 → 절차적
클래스 객체 캡상다추 → 객체지향
goto 적극 활용 → 구조적 설명으로 틀림
```
