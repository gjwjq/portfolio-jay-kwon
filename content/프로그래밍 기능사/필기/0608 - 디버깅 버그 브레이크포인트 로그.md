## 버그

버그는 **프로그램의 오류나 결함**이다.

예시:

```
계산 결과 오류 / 버튼 작동 안 함 / 프로그램 종료 / 화면 깨짐
```

## 핵심 암기

버그 / 프로그램 오류나 결함

---

## 디버깅

디버깅은 **프로그램 오류를 찾아서 수정하는 과정**이다.

```
오류 발견 / 원인 찾기 / 코드 수정 / 다시 실행 확인
```

## 핵심 암기

디버깅 / 오류 찾기 및 수정

---

## 브레이크포인트

브레이크포인트는 디버깅할 때 **프로그램 실행을 특정 줄에서 잠시 멈추는 기능**이다.

확인할 수 있는 것:

```
변수 값 / 실행 흐름 / 오류 위치 / 조건 변화
```

## 핵심 암기

브레이크포인트 / 실행 잠시 중단 / 상태 확인

---

## 로그

로그는 **프로그램 실행 중 발생한 상태나 오류 정보를 기록한 것**이다.

예시:

```
로그인 성공 / 파일 저장 실패 / 서버 오류 발생 / 결제 요청 완료
```

## 로그 역할

| 역할 | 의미 |
| --- | --- |
| 오류 추적 | 문제가 어디서 발생했는지 확인 |
| 상태 기록 | 실행 중 상태를 남김 |
| 원인 분석 | 장애 발생 시 분석 자료로 사용 |

## 핵심 암기

로그 / 상태 및 오류 정보 기록
