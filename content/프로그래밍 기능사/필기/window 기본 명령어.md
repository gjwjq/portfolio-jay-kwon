# Windows 기본 단축키 🪟

| 단축키 | 기능 |
| --- | --- |
| F1 | 도움말 |
| F2 | 이름 변경 |
| F5 | 새로고침 |
| Ctrl + Esc | 시작 메뉴 |
| Alt + Enter | 속성 |
| Ctrl + W | 창 닫기 |
| Alt + F4 | 프로그램 종료 |
| Print Screen | 전체 캡처 |
| Alt + Print Screen | 활성 창 캡처 |
| Alt + Esc | 실행 창 전환 |
| Alt + Tab | 프로그램 전환 |
| Ctrl + Shift + Esc | 작업 관리자 |
| Shift + F10 | 바로가기 메뉴 |
| Shift + Delete | 완전 삭제 |
| Ctrl + A | 전체 선택 |
| Ctrl + C | 복사 |
| Ctrl + X | 잘라내기 |
| Ctrl + V | 붙여넣기 |
| Ctrl + Z | 실행 취소 |
