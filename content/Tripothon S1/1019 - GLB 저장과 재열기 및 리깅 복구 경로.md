> **2026-10-19 · 파일이 있어도 다시 열지 못하는 문제까지**

## 핵심 흐름 안정화

- GLB의 헤더뿐 아니라 장면·버퍼·메시·접근자 등 파일 구조와 현재 로더 호환성을 검사하도록 보완했다.
- 업로드가 저장되었는지 불확실할 때 기존 정보를 보존하고 재시도를 안내하도록 정리했다.
- 만료된 모델 주소는 인증된 요청으로 최신 주소를 얻어 다시 열도록 보완했다.
- 계정이 교체되면 이전 개인 모델과 늦게 도착한 응답이 남지 않도록 세션 상태를 정리했다.
- 불완전한 공급자 응답이 실패나 재조회로 잘못 이어지는 경로를 수정했다.
- 보관된 외형에서 명시적으로 움직임을 재시도하는 복구 DB 함수를 운영에 적용하고 정의와 권한을 조회해 확인했다.

## 이동 실험은 성공으로 처리하지 않았다

그릇 옆에서 나가지 못하는 문제에 자세 복원과 짧은 옆걸음을 시험했지만, 실제 모델의 PC·모바일 크기 모두 물→놀이 전환에 실패했다. 해당 이동 실험은 배포에서 제외했다. 저장·인증·생성 응답 수정과 이동 정체의 해결 여부를 구분했다.

## 입력 이미지도 다시 보완

양쪽 눈이 잘 보이도록 몸 전체의 각도를 약 45도로 바꾸고, 머리와 몸의 방향은 유지하도록 요청 조건을 수정했다. 등이 굽거나 다리를 접은 자세를 피하고, 얼굴 밖으로 긴 수염이 뻗어 목 텍스처에 찍히지 않도록 조건도 정리했다.

**남은 범위:** 프롬프트 조건 검사가 실제 유료 생성 품질을 보장하지는 않는다. 운영 SQL 적용도 실제 유료 재시도·리깅 성공을 확인했다는 뜻은 아니다.
