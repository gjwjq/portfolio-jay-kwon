> **2026-10-14 · 버튼이 뜻하는 행동과 실제 반응을 맞추기**

## 사용자 요청 요약

작동이 불분명한 선택지를 줄이고, 불러주면 현재 사용자의 시점을 향해 돌아와야 한다는 요청이 있었다. 사진 저장과 시점 전환 아이콘의 의미도 구분할 필요가 있었다.

## 조작과 화면 정리

- ‘이리 와’와 불러주기를 같은 다가오기 행동으로 통합하고 현재 시점에 반응하도록 보완했다.
- 나만의 명령어를 실제 행동인 물·밥 주기, 캣타워 오르기, 다가오기, 앉기, 쉬어가기 중심으로 정리했다.
- 기능과 맞지 않는 성격·기억 선택지와 쓰다듬기 항목을 정리했다.
- 시점 전환은 눈 아이콘, 순간 이미지 저장은 카메라 아이콘으로 구분했다.
- 홈 메뉴를 추가하고 캣타워 위 앉기 거절 조건을 수정했다.
- 타워 받침을 누를 때 부적절하게 나오는 안내를 정리했다.
- 소파 아래 장식 천과 컵의 원형 손잡이를 제거했다.

## 로그인 화면과 실제 인증 상태

다른 컴퓨터에서 로그인한 뒤 서버는 만료를 알리는데 헤더에는 로그인 상태가 남는 문제가 보고되었다. 인증 오류와 계정 전환 시 개인 화면·모델 상태를 함께 정리하고 재로그인 안내로 연결하도록 보완했다. 다른 기기 로그인이 유일한 원인이었다고 단정하지는 않는다.

## 생성 실패와 모바일 입력

리깅 실패 뒤에도 보관된 외형을 다시 열 수 있는 복구 흐름을 보완했다. 모바일에서 말 걸기를 누르자마자 입력칸에 포커스가 생겨 키보드가 시야를 가리는 동작도 제거했다.

**확인 범위:** 단위·모의 인증 브라우저·배포 코드 확인과 실제 계정·실제 휴대폰 사용은 구분했다. 모든 상황에서 호출이 무조건 성공하거나 모든 리깅 실패가 해결되었다고 기록하지 않는다.
