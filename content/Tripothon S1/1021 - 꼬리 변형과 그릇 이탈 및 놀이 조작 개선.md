> **2026-10-21 · 수상 뒤에도 실제 사용 과정을 계속 고치기**

## 새로 받은 피드백

앉을 때 두꺼운 꼬리가 뚫리거나 꺾여 보였고, 점프에서는 앞발이 충분히 뻗지 않았다. 그릇 옆에 들어가면 회전만 하며 나오지 못하는 문제도 다시 보고되었다. 낚싯대 놀이를 끄기 어렵고 앉기를 매번 글로 입력해야 한다는 불편도 있었다.

## 원인과 수정

| 문제              | 확인한 내용과 대응                                                                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 꼬리 표면 변형    | 두 모델의 원본·중립 자세는 정상이고 사이트의 앉기에서 변형이 재현되었다. 꼬리 피부 가중치와 앉기 회전을 보완했다. 유료 재생성 없이 사이트 제어를 수정했다.    |
| 점프 앞발         | 관절 길이를 유지하면서 제한된 어깨 회전과 앞발 뻗기를 적용했다.                                                                                               |
| 그릇 옆 이동 정체 | 짧은 바깥 방향 이동 목표를 유지하고, 거부된 이동은 위치와 관절 자세를 함께 복원했다. 실제 수용한 이동 거리만 보행에 반영하고 CPU 표면·상위 좌표를 동기화했다. |
| 놀이 종료         | 낚싯대 버튼 재클릭과 Esc로 종료하도록 보완했다. 공중에서는 현재 점프를 안전하게 착지한 뒤 멈춘다.                                                             |
| 앉기 접근성       | 앉기 버튼과 고양이 짧은 클릭·탭을 추가했다. 드래그나 놀이 조준과 구분했다.                                                                                    |

## 확인한 범위

실제 문제 모델 두 개의 CPU·GPU 검사와 관련 단위 검사 165개, PC·모바일 크기의 브라우저 흐름 10개를 확인했다. 초기 모바일 그릇 이탈 실패는 수정 후 다시 검사했으며 실패를 성공 횟수에 섞지 않았다. 운영 정적 코드 반영도 확인했다.

이 근거가 실제 휴대폰 하드웨어, 운영 계정의 모든 흐름, 모든 체형의 자연스러운 움직임까지 보장하는 것은 아니다. 공급자 리깅이 실패한 모든 모델이 복구되었다는 의미도 아니다.

## 대회 이후 기록과 포트폴리오

이날 이음을 활용한 전국민 AI 경진대회 신청을 마쳤고, 제작 배경·AI 활용·다른 사용자의 재현 가능성을 문장으로 정리했다. 웹 개발 취업에 연결할 수 있는 다음 대회와 프로젝트도 검토했다. Tripothon의 수상 결과와 이후 다른 대회 참가 기록은 구분했다.

수상 사진을 포함해 날짜별 개발 과정을 포트폴리오로 남기기로 했다. ‘상을 받았다’에서 끝내기보다 어떤 요청을 받았고 어떻게 수정했는지까지 설명할 수 있는 기록을 만들고자 한다.
